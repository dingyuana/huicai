## 1. 模块定位

管理核销工作台、应收/应付单据、预收/预付、坏账计提、账龄分析、客户对账单、采购退货。

**做什么**：核销（匹配应收/应付 + 执行核销）、预收预付、坏账计提、账龄分析、客户对账单、采购退货。

**不做什么**：
- 不做应收/应付自动催收
- 不做催收/收款管理
- 不做合同管理（属于 Agency 分支）

## 3. 核心业务规则

### 3.1 核销架构

```
银行流水 → B类路由 → 收款单/付款单(DRAFT) → 核销工作台（唯一入口）→ 核销单 → 凭证
```

- 银行流水不直接参与核销，必须先生成收款单/付款单
- 核销仅支持主业购销应收/应付，暂不支持其他类型

### 3.2 核销规则

| 规则 | 说明 |
|------|------|
| 匹配方式 | 1. 系统推荐（按客户/金额/时间）2. AI 辅助匹配 3. 手工选择 |
| 核销金额 | 可部分核销；核销后剩余余额继续可核销 |
| 核销凭证 | 核销后自动生成凭证，需人工审核过账 |
| 容差 | 允许设置差异比例；差额自动计入差异处理 |

### 3.3 账龄分析

| 分档 | 天数 | 风险等级 |
|------|------|---------|
| 0-30天 | ≤30 | 正常 |
| 31-60天 | 31-60 | 关注 |
| 61-90天 | 61-90 | 风险 |
| 91-180天 | 91-180 | 高风险 |
| 180天以上 | >180 | 逾期 |

### 3.4 坏账计提

| 分档 | 计提比例 |
|------|---------|
| 0-30天 | 0% |
| 31-60天 | 5% |
| 61-90天 | 10% |
| 91-180天 | 30% |
| 180天以上 | 100% |

## 4. 验收标准

| ID | BDD 场景 |
|----|---------|
| AT-01 | Given 有应收和付款单 When 进入核销工作台 Then 推荐匹配 |
| AT-02 | Given 匹配完成后 When 执行核销 Then 应收余额减少 + 核销单创建 |
| AT-03 | Given 核销完成 When 追溯 Then 应收→核销单→凭证链路完整 |
| AT-04 | Given 账龄数据 When 查询账龄分析 Then 返回5档分布 |
| AT-05 | Given 应收单据(180天以上) When 计提坏账 Then 计提100% |
