## 1. 模块定位

管理系统基础数据：会计科目、会计期间、用户/角色/权限、客商档案、审计日志、摘要库、分类规则、批量导入导出。

**做什么**：所有模块的基础档案管理和系统配置。

**不做什么**：
- 不做员工花名册管理（仅作为核算维度使用）
- 不做考勤/工资管理（员工仅用于核算维度）
- 不做客户CRM（Agency 分支）

## 3. 核心业务规则

### 3.1 会计科目规则

| 规则 | 说明 |
|------|------|
| 编码规则 | 4-6-4 层级（如 1001/100101/10010101） |
| 层级 | 支持无限层级 |
| 科目属性 | 资产/负债/权益/成本/损益/共同类 |
| 辅助核算 | 客户/供应商/部门/项目/员工 |
| 末级科目 | 仅末级科目可过账 |
| Excel 导入 | 支持批量导入，含重复编码检测 |

### 3.2 会计期间规则

| 状态 | 说明 |
|------|------|
| OPEN | 可录入凭证 |
| CLOSED | 期末已结账，不可录入 |
| LOCKED | 手动锁定，不可操作 |

### 3.3 RBAC 权限

| 角色 | 权限范围 |
|------|---------|
| SUPER_ADMIN | 系统全部 |
| AGENCY_ADMIN | 代理公司下全部企业 |
| ACCOUNTANT | 仅分配给自己的企业 |
| REVIEWER | 全部可读，不可写 |
| ASSISTANT | 仅分配给自己的企业，只可录入 |
