## 1. 模块定位

管理固定资产卡片、折旧计提、资产处置、盘点、资产类别。

**做什么**：资产卡片 CRUD、折旧计算与凭证、资产处置、盘点差异处理。

**不做什么**：
- 不做资产图片/照片管理
- 不做 GPS 定位/移动资产追踪
- 不做维修管理
- 不做资产租赁

## 3. 核心业务规则

### 3.1 折旧方法

| 方法 | 说明 | 适用范围 |
|------|------|---------|
| 平均年限法 | 每月折旧 = (原值-残值)/折旧月数 | 默认 |
| 工作量法 | 单位工作量折旧 = (原值-残值)/总工作量 | 设备类 |
| 双倍余额递减法 | 前两年高折旧，最后两年转平均 | 电子设备 |
| 年数总和法 | 前高后低，按剩余年数比例 | 特殊资产 |

### 3.2 折旧凭证

| 规则 | 说明 |
|------|------|
| 触发 | 月末自动计提 |
| 借方 | 管理费用/制造费用/研发费用（按部门/项目分摊） |
| 贷方 | 累计折旧(1601) |

### 3.3 资产处置

| 规则 | 说明 |
|------|------|
| 处置类型 | 报废/出售/捐赠 |
| 处置凭证 | 借：固定资产清理 + 累计折旧；贷：固定资产原值 |
