## 1. 模块定位

报表中心三大表现状"**数据底层正确、表层呈现失信**"：平衡校验通过但用户肉眼加总对不上（①），累计数逻辑双处 bug（②），现金流不闭环（③）。本 PRD 分三层：先止血（P88 缺陷修复），再体验（P89 显示+穿透），后进阶（P90 保留项）。

**前置事实（已 trace 代码确认）**：
- ① 后端 `balanceSheet()` 把本年利润（4103+当期 6xx）单列算入合计与平衡校验，但前端权益区只渲染 `equity` 数组 → 行丢失、合计差 27
- ② 后端 `incomeStatement()` L176 `cumulativeProfit = cumRevenue - cumCost` 漏 66xx 费用与 other_expense（SQL 已查 `cumulative_cost_expense`，Java 未消费）；前端 `IncomeStatementView.vue` L54-58 本年累计列除营业收入外**硬编码 0**
- ③ `cashFlowStatement()` 仅返 In/Out/Net，无期初/期末余额行；1002 科目余额数据已具备

> **根因**：现金流量表已有 `fixed` 骨架保护模式，利润表漏做（7 行全裸露）。

## 4. 设计要点

### 4.1 P88 缺陷修复（P0，止血）
- **① 平衡恐慌**：后端把 `currentYearProfit` 作为虚拟行并入 `equity` 行数组（保留现有字段向后兼容），前端按数组渲染即自动出现该行；验收 = 权益区逐行加总 = 所有者权益合计
- **② 累计数**：后端 `cumulativeProfit` 补减 `cumulative_cost_expense`（SQL 已有）+ other_expense 累计（SQL 补查）；前端删 L54-58 硬编码 0，全部走 `result` 字段
- **③ 现金流闭环**：`cashFlowStatement` 增加 `openingCash`（1002+1001 期初余额合计）/`closingCash`（=opening+totalNet）两字段 + 一致性校验 `closingCash == 1002 期末余额`（差异提示而非阻断）

### 4.2 P89 显示与交互
- 金额格式化统一工具函数（千分位 + 2 位 + 负数红）替换各报表视图 `toFixed(2)`
- 穿透链路：`/reports/subject-balance/{code}` 行点击 → `/voucher?subjectId=&period=` 凭证列表（既有端点，前端加路由参数）
- 对比列数据：资产负债"年初数"= 年初期间余额快照（需补取数）；利润表"上期金额"= 上期同期
- 导出：现有 `writeExcel` 扩模板（标题行/期间/制表人取当前用户/审核人留白）

### 4.3 P90 进阶（保留 3 砍 2，见 §7）
- 重分类：**纯展示层**——预付贷方余额行标黄提示"建议重分类至应付"，不动账（做账重分类属期末手工账，慧财定位不做）
- 辅助核算展开：科目余额表行加展开按钮 → P60 辅助核算明细
- 异常高亮：规则表驱动（现金贷方余额、6xx 收入倒挂为借方、4103 连续借方=亏损提醒），复用 t_financial_metric 或独立小规则表

## 5. 验收标准（BDD）

- **P88-BD1**：Given 年初实收资本 20 万、本年利润 -27 When 查 202407 资产负债表 Then 权益区含"本年利润 -27.00"行，逐行加总 = 212,773.07 = 合计
- **P88-BD2**：Given 3 期均有 27 元财务费用 When 查第 3 期利润表 Then 本年累计营业利润 = 3 × 本期值（非 0）
- **P88-BD3**：Given 期初银行 20 万、净流 -75,684.30 When 查现金流量表 Then 显示期初 200,000.00 / 期末 124,315.70，期末 = 1002 期末余额（或差异提示）
- **P89-BD1**：Given 报表任一金额 When 渲染 Then 千分位右对齐；负数红色
- **P89-BD2**：Given 利润表"营业收入"行 When 点击数字 Then 2 跳内达该科目凭证明细
- **P90-BD1**：Given 预付账款 1002 贷方余额 5,000 When 查资产负债表 Then 该行黄色提示重分类，资产/负债两侧调整后视图可切换
- **P91-BD1**：Given 某期间利润表全部金额字段为 0 When 渲染利润表 Then 7 行法定结构行（一、营业收入 / 减:营业成本 / 二、毛利 / 减:期间费用 / 三、营业利润 / 减:其他支出 / 四、利润总额）全部在场，金额显示 0.00 而非整行省略
- **P91-BD2**：Given 利润表任意数据 When 渲染 Then 页面不出现"隐藏零值行"开关，取而代之为"法定格式 · 结构固定"提示；科目余额表与现金流量表的该开关不受影响
