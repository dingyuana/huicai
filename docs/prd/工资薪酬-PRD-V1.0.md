## 1. 模块定位

管理工资表录入/导入、个税计算、社保公积金、工资单（SALARY docType）全流程。

**当前状态**：仅 SALARY docType 注册在 `BusinessDocServiceImpl.DOC_TYPE_CODE` 中（编号前缀 `GR`），支持工资单手工录入。独立工资模块（`sme/salary` 包、工资表、个税计算、社保公积金）**完全待建**，当前整体完成度约 **10%**。

## 3. 核心业务规则

### 3.1 个税计算（累计预扣法）

| 项目 | 规则 |
|------|------|
| 免征额 | 5000 元/月 |
| 专项附加 | 子女教育2000/月 + 继续教育400/月 + 住房贷款利息1000/月 + 赡养老人2000/月 |
| 累计应纳税所得额 | 累计收入 - 累计免征额 - 累计专项附加 - 累计已缴税额 |
| 税率表 | 3%~45% 七级超额累进（见 DSN-工资薪酬管理.md） |

### 3.2 社保公积金比例

| 项目 | 单位比例 | 个人比例 |
|------|---------|---------|
| 养老保险 | 16% | 8% |
| 医疗保险 | 9% | 2% |
| 失业保险 | 0.5% | 0.5% |
| 工伤保险 | 0.5% | 0% |
| 生育保险 | 0.8% | 0% |
| 住房公积金 | 12% | 12% |

> 以上比例为参考，实际按当地政策配置。

### 3.3 工资单凭证

| 借方 | 贷方 |
|------|------|
| 管理费用-工资(2211) | 应付职工薪酬-工资(2211) |
| | 应付职工薪酬-社保个人 |
| | 应交税费-个人所得税 |
| | 银行存款(1002) |

## 4. 验收标准

| ID | BDD 场景 |
|----|---------|
| AT-01 | Given 月薪20000(累计1月) When 个税计算 Then 应纳税额=800 |
| AT-02 | Given 月薪20000(累计12月) When 个税计算 Then 按年度累计预扣 |
| AT-03 | Given 工资表录入 When 生成工资单 Then 状态=DRAFT + 凭证=DRAFT |
| AT-04 | Given DRAFT工资单 When 审核 Then 状态=APPROVED + 凭证生成 |
