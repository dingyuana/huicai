## 1. 模块定位

代账公司管理多客户企业的业务系统：多租户切换、代理内角色管理、客户分配、批量操作、客户合同/续费。

**做什么**：多客户账套管理 + 代理内角色体系 + 客户分配 + 批量操作 + 客户管理。

**不做什么**：
- 不做客户CRM/看账门户（V2.0）
- 不做移动端原生App
- 不做批量报税（V2.0）

## 3. 核心业务规则

### 3.1 代理内角色权限矩阵

| 操作 | AGENCY_ADMIN | ACCOUNTANT | REVIEWER | ASSISTANT |
|------|:-----------:|:----------:|:--------:|:---------:|
| 查看客户列表 | 全部 | 仅自己的 | 全部 | 仅自己的 |
| 切换客户企业 | 全部 | 仅自己的 | 全部（只读） | 仅自己的 |
| 凭证录入 | 全部 | 仅自己的 | — | 仅自己的 |
| 凭证审核 | 全部 | — | 全部 | — |
| 报表查看 | 全部 | 仅自己的 | 全部 | 仅自己的 |
| 发票管理 | 全部 | 仅自己的 | 全部 | 仅自己的 |
| 管理会计（分配/启停） | 是 | — | — | — |
| 批量操作 | 全部 | 仅自己的 | — | — |
| 合同管理 | 全部 | 仅自己的 | 全部 | — |
| 系统管理 | — | — | — | — |

### 3.2 数据权限三层防线

| 防线 | 层级 | 说明 |
|------|------|------|
| 第一层 | 前端路由守卫 | 按 agencyRole 控制菜单可见性和企业切换范围 |
| 第二层 | EnterpriseController | 切换企业时校验分配关系 |
| 第三层 | MyBatis 拦截器 + PostgreSQL RLS | 按 enterprise_id 过滤数据 |

### 3.3 客户分配规则

| 规则 | 说明 |
|------|------|
| 分配操作 | 由 AGENCY_ADMIN 执行 |
| 分配记录 | 记录 assigned_by/assigned_at |
| 取消分配 | 软删除实现，记录 unassigned_by/unassigned_at |
| 可见范围 | ACCOUNTANT/ASSISTANT 登录后 enterpriseList 仅包含分配给自己的企业 |

## 4. 验收标准

| ID | BDD 场景 |
|----|---------|
| AT-01 | Given AGENCY_ADMIN When 查看客户列表 Then 返回全部客户 |
| AT-02 | Given ACCOUNTANT(分配给A企业) When 查看客户列表 Then 仅返回A企业 |
| AT-03 | Given AGENCY_ADMIN When 分配A企业给会计B Then 分配记录写入 |
| AT-04 | Given 会计B When 切换企业到C(未分配) Then 拒绝 |
| AT-05 | Given 批量导入发票(多租户) When 执行 Then 每租户独立处理 |
