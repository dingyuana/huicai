## 1. 模块定位

经营状况分析 = 连接"核算财务"与"管理财务"的报表层：把已有的三大表/杜邦/指标/预算数据，转化为 CFO/管理层可直接决策的**差异、预警、预测、总览**四类视图。

**只做**：描述性（发生了什么）+ 诊断性（为什么发生）中，**有数据基础、可纯 SQL 聚合**的部分。
**不做**：需要新数据模型（阿米巴/成本中心）或外部数据（行业对标）或 AI（NLG 月报）的能力（详见 §6）。

本 PRD 来源：外部《财务软件-经营状况分析功能需求分析书》评估裁剪（评估记录：§6 不做的事 + 各砍项理由）。

## 4. 分析规则

### 4.1 P80 预算执行差异
- **数据源**：`t_budget`（预算数，按科目+期间+执行维度）+ `t_subject_balance`/凭证发生额（实际数，按科目+期间）
- **口径**：实际数 = 该科目该期间**发生额合计**（与利润表口径一致）；预算未编制的科目实际数照常列示、预算数=0
- **达成率** = 实际/预算 ×100%；费用类科目 >100% 即超支（红），收入类 <100% 即未达（红）
- **差异动因分析（价格差/用量差）不做**——SME 供应商价格波动直接看采购发票，不值得建差异计算引擎

### 4.2 P81 指标预警扫描
- **数据源**：`t_financial_metric`（code/name/formula/threshold/alert_enabled，已建）
- **扫描**：对 `alert_enabled=true` 的指标，按 formula 计算当期值，`abs(value - threshold)` 越限（方向由指标方向属性定：higher_worse/lower_worse）→ 生成预警记录
- **去重**：同一指标同期间只保留一条未读预警（幂等，重复扫描不重复生成）
- **通知**：预警落库即完成；推送通道（企微/钉钉 webhook）留 P2，不在 P81 范围
- **人工**：忽略/解决必须人工操作（铁律：系统不自动消除预警状态）

### 4.3 P82 现金流静态预测（30/60/90 天）
- **模型（静态版，无压力测试）**：
  - 未来 30/60/90 天**现金流入** = 未收应收按账龄段 × 历史回收率（账龄越长回收率越低，回收率按近 12 期实际回收计算，无历史的用账龄段默认曲线）
  - 未来 30/60/90 天**现金流出** = 未付应付按到期日 + 预算内已排支出
  - 每日净流量 → 累计资金缺口曲线
- **不做**：大客户延期/银行抽贷等情景模拟（压力测试），SME 用"账龄段回收率"静态曲线已够

### 4.4 P83 管理驾驶舱
- **纯聚合层**：KPI 卡（营收/净利/毛利率/现金缺口）= 指标端点 + P82 缺口；趋势 = trend 端点；利润瀑布 = 利润表科目分解（收入→毛利→净利各环节扣减）
- **零新计算端点**，全部复用 ReportController/AnalysisService 既有 10 个端点；前端一个新视图
- **穿透**：KPI/瀑布节点点击 → 跳转对应报表/科目余额/凭证（既有路由）

## 5. 验收标准（BDD）

- **P80-BD1**：Given 科目 6601 预算 10 万、实际 12 万 When 查 202609 预算差异 Then 差异 +2 万、达成率 120%、红色标识
- **P80-BD2**：Given 科目未编预算 When 查差异 Then 实际数列示、预算数 0、达成率"—"
- **P81-BD1**：Given 流动比率公式值 0.8、阈值 1.0、方向 higher_worse、alert_enabled When 手动扫描 Then 生成 1 条 UNREAD 预警；再扫一次 Then 不重复生成
- **P81-BD2**：Given 1 条 UNREAD 预警 When 经理手动忽略 Then 状态→IGNORED 留操作人
- **P82-BD1**：Given 应收账龄含 30-60 天 5 万、近 12 期该段回收率 80% When 生成 90 天预测 Then 第 45 天（中位预期）流入 4 万计入曲线
- **P82-BD2**：Given 某日累计净流量转负 When 查看曲线 Then 该日起缺口高亮
- **P83-BD1**：Given 驾驶舱首屏 When 加载 Then KPI 卡/趋势/瀑布三区块 <3s（复用端点并行请求）
- **P83-BD2**：Given 瀑布"毛利"节点 When 点击 Then 穿透至利润表明细

## 6. 不做的事（裁剪记录，防复发）

| 项 | 理由 |
|----|------|
| 阿米巴/利润中心/分摊引擎/OLAP 多维立方体 | SME 科目体系无成本中心辅助核算、无变动/固定成本标记——**数据基础不存在**，建出来全是零。金蝶云·星空级能力，慧财目标客户不用 |
| 本量利 CVP（盈亏平衡/安全边际） | 依赖"成本分类为变动/固定"的标记数据，同上无基础；SME 老板看预算差异+毛利率即可 |
| 行业对标雷达 | 无外部行业数据源，数据不能编造 |
| 低代码拖拽看板 | 用户已有 Excel/BI 替代；慧财定位"在线查看+导出"，DSN-报表分析 已标注拖拽设计器为已知差距（P3） |
| 现金流压力测试（抽贷/延期模拟） | P2 静态曲线已覆盖 90% 场景；情景模拟维护成本高、SME 低频 |
| 行级/字段级数据权限 | 慧财为组织级+租户级隔离（MyBatis 拦截器），SME 少人不需要行级 |
| NLG 智能月报/AI 异动归因 | 项目 AI 排除原则（竞品核查 G 系列同款裁剪）；DSN 已标 P3 暂缓 |
| 预算差异动因分析（价差/用量差） | 伪需求——SME 价格波动看采购发票即可，见 §4.1 |
