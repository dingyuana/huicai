## 1. 模块定位

管理银行账户、银行流水导入、智能分类、银行对账、余额调节表、现金/银行日记账、票据。

**做什么**：银行流水导入+AI分类、银行对账+余额调节表、现金/银行日记账、票据管理。

**不做什么**：
- 不做银企直连（保持 Excel 导入）
- 不做资金调拨
- 不做资金计划

## 3. 核心业务规则

### 3.1 流水分类（A/B/C 路由）

| 类型 | 说明 | 处理 |
|------|------|------|
| A 类（收入） | 收款类流水 | 自动生成收款单→核销工作台 |
| B 类（支出） | 付款类流水 | 自动生成付款单→核销工作台 |
| C 类（转账） | 转账类流水 | 自动生成转账单（TRANSFER） |

### 3.2 银行对账规则

| 规则 | 说明 |
|------|------|
| 匹配方式 | 银行对账单 vs 银行日记账（按金额+日期+对方户名） |
| 已收/已付项 | 银行有、企业也有 → 已匹配 |
| 已收未达 | 银行有、企业没有 → 已收未达项 |
| 已付未达 | 企业有、银行没有 → 已付未达项 |
| 调节后余额 | 两侧必须相等 |

### 3.3 余额调节表

| 项目 | 企业账 | 银行账 |
|------|--------|--------|
| 企业账面余额 | 基准 | 参考 |
| 加：已收未达 | + | — |
| 减：已付未达 | — | — |
| 加：已付未达 | — | + |
| 减：已收未达 | — | — |
| **调节后余额** | = | = |

## 4. 验收标准

| ID | BDD 场景 |
|----|---------|
| AT-01 | Given 银行流水(收款) When 导入+AI分类 Then 分类=A类 + 自动生成收款单 |
| AT-02 | Given 银行对账单+银行日记账 When 对账 Then 返回已达/已收未达/已付未达 |
| AT-03 | Given 已对账数据 When 生成余额调节表 Then 两侧余额相等 |
| AT-04 | Given 日记账(现金/银行) When 查询 Then 返回按日期排列的逐笔记录 |
| AT-05 | Given 流水(转账) When 分类=C Then 自动生成转账单(DRAFT) |
