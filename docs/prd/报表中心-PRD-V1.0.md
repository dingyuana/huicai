## 1. 模块定位

生成三大报表（资产负债表/利润表/现金流量表）和财务分析（科目余额表/杜邦分析/趋势分析）。

**做什么**：四大标准报表、科目余额表、杜邦分析、趋势分析、Excel 导出。

**不做什么**：
- 不做多期间合并报表
- 不做现金流量表直接录入（通过科目映射间接生成）
- 不做 BI 仪表板
- 不做经营分析驾驶舱（远期 V2.0）

## 3. 报表规则

### 3.1 资产负债表

| 规则 | 说明 |
|------|------|
| 公式 | 资产 = 负债 + 所有者权益 |
| 分组 | 1xxx=资产、2xxx=负债、3xxx/4xxx=所有者权益 |
| 余额方向 | 资产类借方为正，负债/权益类贷方为正 |
| 数据来源 | `t_subject_balance` 期末余额 |
| 试算平衡 | 资产 ≠ 负债+权益时不报错（损益未结转导致的正常差额） |

### 3.2 利润表

| 规则 | 说明 |
|------|------|
| 公式 | 净利润 = 收入 - 费用 |
| 收入科目 | 6xxx |
| 费用科目 | 5xxx |
| 数据来源 | 本期发生额 |

### 3.3 现金流量表

| 规则 | 说明 |
|------|------|
| 分类 | 经营活动/投资活动/筹资活动 |
| 数据来源 | 科目映射（1001 现金/1002 银行存款相关分录） |

### 3.4 科目余额表

| 规则 | 说明 |
|------|------|
| 展示 | 全部科目 |期初借方/贷方 + 本期借方/贷方 + 期末借方/贷方 |
| 筛选 | 支持零余额过滤 |
| 层级 | 按科目树层级展示（一级/二级/三级/末级） |

### 3.5 杜邦分析

| 指标 | 公式 |
|------|------|
| ROE | 净利润 / 净资产 |
| ROA | 净利润 / 总资产 |
| 净利率 | 净利润 / 营业收入 |
| 总资产周转率 | 营业收入 / 总资产 |
| 权益乘数 | 总资产 / 净资产 |

### 3.6 趋势分析

| 规则 | 说明 |
|------|------|
| 范围 | 用户选择起止期间 |
| 维度 | 营业收入、营业成本、净利润、资产总额 |
| 展示 | ECharts 折线图 |

## 4. 验收标准

| ID | BDD 场景 |
|----|---------|
| AT-01 | Given 有期末余额 When 查询资产负债表 Then 资产=负债+权益（损益已结转） |
| AT-02 | Given 有发生额 When 查询利润表 Then 收入-费用=净利润 |
| AT-03 | Given 有现金/银行存款分录 When 查询现金流量表 Then 返回三类现金流 |
| AT-04 | Given 有多科目 When 查询科目余额表(零余额) Then 仅返回有余额科目 |
| AT-05 | Given 有损益数据 When 查询杜邦分析 Then 展示5个指标且数据正确 |
| AT-06 | Given 有3个月数据 When 查询趋势分析 Then 返回3条数据点 |
| AT-07 | Given 报表导出 When Excel下载 Then 内容完整+格式正确 |

## 5. 不做的事

| 不做 | 理由 |
|------|------|
| 合并报表 | 集团场景，V2.0 |
| 现金流量表直接录入 | 通过科目映射间接生成，避免数据源分裂 |
| 经营分析驾驶舱 | V2.0 |
| 预算执行对比 | 属于预算管理模块 |
| NL2SQL 经营分析 | V2.0 |
