## 1. 模块定位

管理预算编制、三级控制（WARN/APPROVE_REQUIRED/BLOCK）、预算调整、预算结转。

**做什么**：预算录入+控制+调整+结转。

**不做什么**：
- 不做预算执行仪表板（报表中心已有趋势分析）
- 不做预算预测（V2.0 AI 预算预测）
- 不做收入预算（仅费用预算）

## 3. 核心业务规则

### 3.1 预算控制

| 控制级别 | 执行率 | 行为 |
|---------|--------|------|
| 无控制 | <80% | 正常执行，不拦截 |
| WARN | 80%-100% | 提交时弹出警告，不拦截 |
| APPROVE_REQUIRED | 100%-120% | 需上级审批后方可提交 |
| BLOCK | >120% | 直接拒绝提交 |

### 3.2 控制触发点

| 业务场景 | 触发时机 |
|---------|---------|
| 费用报销提交 | 实时校验预算余额 |
| 付款申请 | 实时校验 |

### 3.3 预算调整

| 类型 | 说明 |
|------|------|
| 追加 | 增加预算金额，需审批 |
| 收回 | 减少预算金额，需审批 |
