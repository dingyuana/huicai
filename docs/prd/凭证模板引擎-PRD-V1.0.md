## 1. 模块定位

凭证生成模板引擎是**业财之间的唯一桥梁**。所有业务单据（发票/业务单据/银行流水）通过此引擎自动生成会计凭证，确保：
- 同一业务类型走同一分录规则，避免人工制证差异
- 凭证编号自动回写业务单据，实现双向追溯
- 已生成凭证的单据锁定，防止重复制证

**核心原则**：
- AI 输出 = 建议，不自动应用（铁律 #2）
- 自动制证产生的凭证初始状态为 DRAFT，需人工审核
- 模板匹配优先于硬编码，硬编码作为降级兜底

## 5. 模板匹配引擎

### 5.1 匹配规则

```
输入: source + classification + direction + amount
  ↓
查询 t_voucher_template 表
  ↓
匹配条件: source = 'BANK_STMT' AND classification = 'business_receipt'
  ↓
找到 → 取模板行（t_voucher_template_line），解析金额变量
  ↓
未找到 → 降级到硬编码规则（AutoGenerationService 内 switch-case）
```

### 5.2 模板变量

| 变量 | 说明 | 示例渲染值 |
|------|------|-----------|
| `${amount}` | 交易金额 | `1000.00` |
| `${summary}` | 摘要文本 | `货款支付` |
| `${direction}` | 资金方向（in/out） | `in` |
| `${counterparty}` | 对方账户名 | `万达公司` |
| `${period}` | 会计期间 | `202607` |
| `${txDate}` | 交易日期 | `2026-07-15` |

### 5.3 模板行方向约束

| 行方向 | 行为 |
|--------|------|
| debit | 确保该行借贷方向为借方，金额从 dr 或 cr 中取 |
| credit | 确保该行借贷方向为贷方，金额从 cr 或 dr 中取 |

## 6. 凭证回写与单据锁定

### 6.1 凭证回写

| 步骤 | 说明 |
|------|------|
| 1 | 生成凭证后，将凭证 ID 写入业务单据的 `generatedVoucherId` 字段 |
| 2 | 凭证号写入业务单据的 `voucherNo` 字段（冗余，方便前端展示） |
| 3 | 业务单据状态更新为 `VOUCHERED`（已生成凭证） |

### 6.2 单据锁定

| 规则 | 说明 |
|------|------|
| 已生成凭证 | 业务单据 `status = VOUCHERED`，禁止编辑 |
| 已生成凭证 | 禁止重复触发 autoGenerate（检查 `generatedDocId` 是否已存在） |
| 未生成凭证 | 业务单据可编辑，编辑后已有的凭证需重新生成 |
| 红冲 | 红冲时自动生成红字凭证，红字凭证状态为 DRAFT |

### 6.3 重复制证防护

```java
// AutoGenerationService 第 116-123 行
long existingDocCount = docMapper.selectCount(
    new LambdaQueryWrapper<BusinessDocEntity>()
        .eq(BusinessDocEntity::getBankStatementId, statementId)
        .eq(BusinessDocEntity::getDeleted, 0));
if (existingDocCount > 0) {
    log.warn("流水 {} 已有 {} 个关联业务单据, 跳过自动生成", statementId, existingDocCount);
    return true;
}
```

## 7. 红冲联动

### 7.1 业务单据红冲→凭证红冲

| 步骤 | 说明 |
|------|------|
| 1 | 业务单据触发红冲（`reverse()`） |
| 2 | 检查原单据是否有已生成凭证（`generatedVoucherId` 非空） |
| 3 | 有 → 自动生成红字凭证（`source = REVERSAL`，`reversedFrom = 原凭证ID`） |
| 4 | 无 → 仅修改业务单据状态，不生成红字凭证 |
| 5 | 红字凭证状态为 DRAFT，需人工审核 |

### 7.2 红字凭证规则

| 规则 | 说明 |
|------|------|
| 来源标记 | `source = 'REVERSAL'` |
| 状态 | `DRAFT`（需人工审核） |
| 分录方向 | 与原凭证互换（原来借方→贷方，原来贷方→借方） |
| 关联字段 | `reversedFrom`（红字→原单） |
| 原单标记 | 原单 `isReversed = true`（V137 新增） |

## 8. 不做的事

| 不做 | 理由 |
|------|------|
| 自动审核/自动过账 | 违反铁律（AI 输出=建议，人不自动应用） |
| 多币种凭证 | 当前单币种 |
| 手工制证替代 | 模板引擎是辅助，不替代手工制证 |
| 凭证合并/拆分 | 无业务场景支撑 |
| 跨期凭证 | 账期控制由期末结账模块处理 |
