## 2. 版本规划

### 2.1 V1.0 底座+SME（当前已完成）

**底座**：全部已实现（含凭证模板、账簿查询、摘要库、分类规则）

**Agency**：多租户基础设施 + 用户认证切换 + 客户管理 + 批量操作骨架已完成（Sprint 1-4），代理内角色体系 + 客户分配待实现（Sprint 5-6）

### 2.2 V1.1 计划

- 工资薪酬模块上线
- Agency 代理内角色体系 + 客户分配机制（P0 阻塞项）
- AI 3个Agent（流水分类/审核建议/核销匹配）

### 2.3 V2.0 远期（未排期）

- 服务流程管理（取票→记账→审核→报税 节点跟踪）
- 工作量统计与绩效

- 批量报税 + 批量生成凭证

## 3. 非功能需求

| 需求 | 指标 | 说明 |
|------|------|------|
| 金额精度 | 小数点后2位 | BigDecimal + NUMERIC(18,2) |
| 响应时间 | 列表查询<2s，操作<1s | 索引优化，Redis缓存 |
| 并发 | 支持50人同时操作 | 单体部署，无需分布式 |
| 可用性 | 99.5% | 单体部署，关键数据备份 |
| 审计 | 所有操作可追溯 | AOP拦截+jsonb快照 |
| 数据隔离 | 组织级+租户级 | MyBatis拦截器注入SQL条件 |
| 前端构建校验 | API路径合规率100% | validate-api-paths.mjs 构建时检查 |
| Entity-DB一致性 | 启动前自动检测 | SchemaValidator + CI脚本 |
