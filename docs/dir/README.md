# DIR — Document Improvement Request

> 用于捕获开发过程中发现的需求模糊、规范缺失、流程不准确问题。
> 每条 DIR 不超过 3 个字段，提交 ≤ 2 分钟。

## 模板

```
DIR-{序号}: {一句话问题描述}
- 类型：需求遗漏 / 规范模糊 / 流程错误 / 技术约束缺失
- 影响范围：{模块/文件/功能}
- 关联：REQ-2026-XXX / P-{编号}
```
