# 慧财财务 — 需求分析书 01：银行流水智能处理

> 版本：V1.0 | 日期：2026-06-12 | 归属：第一阶段
> 对应项目说明书：§4.5 出纳管理、§4.12.1.1 银行流水导入智能分类、§4.12.2.1/2.2 自动生成单据/凭证

---

## 1. 业务概述

银行流水是企业财务系统的核心数据入口之一。出纳每日需从网银下载对账单，手动整理、分类、录入系统。该流程重复性强、效率低、易出错。

本模块以银行流水为驱动源，实现从数据导入、智能分类、自动生成单据/凭证的全链路自动化，让出纳核心职能从"录入"升级为"审核与例外管理"。

---

## 2. 业务流程

```
上传对账单文件 (Excel/CSV)
  ↓
列名智能识别（两阶段映射 + 级联回退）
  ↓
数据预校验（日期格式/金额解析/必填项检查）
  ↓
预览确认（展示解析结果表格，错误行红色高亮）
  ↓
自动分类引擎（两段式，100%有结果）
  ├─ 规则引擎（8条种子规则，优先级排序，第一命中即停）
  └─ 兜底启发式（9级关键词分组，确保兜底）
      ↓ (可选) AI 语义增强
  ↓
导入结果 → 流水进入"待确认"状态
  ↓ 出纳在工作台审查
确认 / 驳回 / 重分类
  ↓
根据分类触发后续处理（**出纳在工作台确认后**才执行）：
  ├─ bank_fee / interest_income → 直接生成凭证草稿
  ├─ tax_payment / social_security → 直接生成凭证草稿
  ├─ insurance_fee → 直接生成凭证草稿
  ├─ business_receipt → 生成收款单（待核销）
  ├─ business_payment → 生成付款单（待核销）
  ├─ internal_transfer → 生成银行转账单
  ├─ salary_payment → 生成付款单（待核销，关联员工档案）
  └─ pending → 归入待处理流水池，人工指定类型
```

## 3. 功能需求

### FR-BANK-01: 文件导入

| 需求 | 说明 |
|:---|:-----|
| FR-BANK-01.1 | 支持 .xlsx / .xls / .csv 格式上传，单文件 ≤ 20MB，单次 ≤ 5000 行 |
| FR-BANK-01.2 | 自动检测文件编码（UTF-8 / GBK / GB18030）|
| FR-BANK-01.3 | 上传后展示导入向导：步骤一（上传）→ 步骤二（预览）→ 步骤三（确认）|
| FR-BANK-01.4 | 预览阶段以表格展示解析结果，含日期/摘要/金额/对方户名/系统建议分类 |
| FR-BANK-01.5 | 校验失败行红色高亮，鼠标悬浮提示具体错误原因（日期格式/金额为空等）|
| FR-BANK-01.6 | 用户可勾选/取消勾选待导入行，确认后开始导入 |
| FR-BANK-01.7 | 导入完成后弹窗显示结果摘要：共解析 N 条，成功 N 条，跳过 N 条（重复），失败 N 条 |
| FR-BANK-01.8 | 支持下载导入错误报告 CSV |

### FR-BANK-02: 列名智能映射

两阶段列名匹配机制，支持中英文及混合变体：

**日期列**（至少识别一种）：
`交易日期` / `记账日期` / `发生日期` / `日期` / `date` / `transaction date` / `txn date` / `入账日期`

**摘要列**（含级联回退）：
主列：`摘要` / `description`
回退：`交易附言` / `备注` / `remarks` / `用途` / `purpose`

**金额列**（三列互斥逻辑）：
- 优先模式：`收入金额` / `贷方金额` / `income` / `credit`（收入）
              `支出金额` / `借方金额` / `expense` / `debit`（支出）
- 降级模式：`金额` / `发生金额` / `交易金额` / `amount`（正值=收入，负值=支出）

**对方户名列**（四级联查）：
1. `付款人名称`（方向=in）/ `收款人名称`（方向=out）
2. 另一方名称（如方向=in 时查 "收款人名称"）
3. `对方户名` / `对方名称` / `对方账户` / `交易对方` / `counterparty`
4. `付款人` / `收款人`

**流水号列**（可选）：
`流水号` / `交易流水号` / `交易编号` / `参考号` / `reference` / `voucher no`

**日期格式自动解析**（支持 10+ 种格式）：
`2006-01-02` / `20060102` / `2006/01/02` / `01/02/2006` / `2006-01-02 15:04:05` / `2006年01月02日` / `02/01/2006` 等

### FR-BANK-03: 交易对手方智能处理

| 需求 | 说明 |
|:---|:-----|
| FR-BANK-03.1 | 导入时自动从摘录提取对手方名称（正则提取 + 排除银行账号）|
| FR-BANK-03.2 | 自动匹配已有客商档案（按名称精确/模糊匹配）|
| FR-BANK-03.3 | 匹配失败时自动创建新客商档案（标记来源"FROM_BANK_TXN"）|

| FR-BANK-03.5 | 不自动创建时，对手方为空则归入待处理流水池 |

### FR-BANK-04: 智能分类引擎

**4.1 分类标准**

系统预置 8 种标准分类（含 1 种兜底）：

| 分类值 | 中文名 | 说明 | 后续处理 |
|:---|:---|:---|:---:|
| bank_fee | 银行费用 | 手续费、工本费、年费、账户管理费 | 直接生成凭证 |
| interest_income | 利息收入 | 存款利息、结息 | 直接生成凭证 |
| business_receipt | 业务收款 | 客户回款、货款收入 | 生成收款单→核销 |
| business_payment | 业务付款 | 供应商付款、货款支出 | 生成付款单→核销 |
| internal_transfer | 内部转账 | 账户间调拨、转存 | 生成银行转账单 |
| tax_payment | 税务缴费 | 增值税、所得税、城建税等 | 直接生成凭证 |
| social_security | 社保缴费 | 社保、公积金 | 直接生成凭证 |
| insurance_fee | 保险费用 | 财产险、责任险等 | 直接生成凭证 |
| pending | 待处理 | 无法自动分类 | 归入待处理流水池 |

**4.2 三层分类架构**

```
阶段一：规则引擎（Java 本地，毫秒级）
  └─ 规则存入 t_classification_rule 表，系统管理员可配置
  └─ 按 priority ASC 排序，逐条检查方向过滤→关键词/正则匹配→第一命中即停
  └─ 8 条种子规则预置（银行手续费/利息收入/业务收款/业务付款/内部转账/税务/社保/保险）

阶段二：兜底启发式（Java 本地，毫秒级）
  └─ 规则引擎未命中时执行
  └─ 硬编码关键词分组按优先级匹配（10 组）
  └─ 确保 100% 流水有分类，绝不丢单

阶段三：AI 语义增强（Python 微服务，可选）
  └─ 规则引擎+兜底置信度均 <60% 时触发
  └─ 调用 Python 匹配服务，对摘要文本做语义嵌入
  └─ 与历史分类模板计算余弦相似度
  └─ 结果写入 ai_suggested_action / ai_confidence / ai_business_scene
```

**4.3 规则引擎详情**

规则属性：

| 属性 | 类型 | 说明 |
|:---|:---|:-----|
| name | VARCHAR(100) | 规则名称，如"银行手续费" |
| rule_type | VARCHAR(30) | keyword（包含匹配）/ keyword_regex（\| 分割）/ counterparty_match（对手方匹配）|
| pattern | TEXT | 匹配模式 |
| match_field | VARCHAR(30) | description（摘要）/ counterparty（对方户名）|
| direction | VARCHAR(10) | in（收入）/ out（支出）/ 空（不限）|
| classification | VARCHAR(50) | 分类结果 |
| priority | INT | 优先级，数字越小越优先 |
| is_active | BOOLEAN | 启用/禁用 |
| debit_subject_id | BIGINT | 借方科目（可选，用于自动凭证）|
| credit_subject_id | BIGINT | 贷方科目（可选，用于自动凭证）|

8 条种子规则：

| 规则名称 | pattern | direction | classification | 优先级 |
|:---|:---|:---:|:---|:---:|
| 银行手续费 | 手续费\|工本费\|年费\|账户管理费 | out | bank_fee | 1 |
| 利息收入 | 利息\|结息\|存款利息 | in | interest_income | 2 |
| 业务收款 | 货款 | in | business_receipt | 3 |
| 业务付款 | 货款 | out | business_payment | 4 |
| 内部转账 | 转账\|转存\|调拨\|上划\|下拨 | (空) | internal_transfer | 5 |
| 税务缴费 | 税\|税务\|缴税\|税金\|税款\|增值税\|所得税\|城建税\|教育费附加\|国家金库\|国库\|印花 | out | tax_payment | 6 |
| 社保缴费 | 社保\|公积金\|养老\|医疗\|失业\|工伤\|生育 | out | social_security | 7 |
| 保险费用 | 保险\|保费\|投保\|财产险\|责任险\|雇主责任险\|意外险 | out | insurance_fee | 8 |

**4.4 兜底启发式分类（10 级优先级）**

| 优先级 | 分组 | 分类 | 关键词 |
|:---:|:---|:---|:---|
| 1 | 银行费用 | bank_fee | 手续费/工本费/年费/短信费/汇费/网银费/账户管理费 |
| 2 | 利息收入 | interest_income | 利息/结息/派息/存款利息 |
| 3 | 保险费用 | insurance_fee | 保险/保费/投保/财产险/责任险/雇主责任险/意外险 |
| 4 | 税务缴费 | tax_payment | 税/增值税/所得税/城建税/教育费附加 |
| 5 | 社保缴费 | social_security | 社保/公积金/养老/医疗/失业/工伤/生育 |
| 6 | 工资发放 | salary_payment | 工资/薪金/奖金/补贴/津贴 |
| 7 | 内部转账 | internal_transfer | 转账/转存/调拨/上划/下拨 |
| 8 | 业务收款(in) | business_receipt | 货款/回款/结算款/预收款 |

**4.5 置信度评估**

| 置信度 | 颜色 | 操作建议 |
|:---:|:---:|:---|
| ≥80%(规则命中) | 🟢 绿色 | 一键确认采纳 |
| 60-79%(兜底/KW匹配) | 🟡 黄色 | 重点核对后再确认 |
| <60%(AI 建议) | ⚪ 灰色 | 建议人工判断 |

### FR-BANK-05: 业务单据出纳确认后创建

**触发时机**：出纳在 FR-BANK-07 工作台确认流水后，**根据分类创建对应业务单据（DRAFT 状态）**，而非导入时自动创建。导入阶段仅完成分类与入库，**不触发单据生成**。

| 流水分类 | 确认后动作 | 单据类型 | 初始状态 | 说明 |
|:---|:---|:---:|:---:|:---|
| business_receipt | 创建收款单 | 收款单 | DRAFT | 关联对方户名匹配的客户，金额自动填入 |
| business_payment | 创建付款单 | 付款单 | DRAFT | 关联对方户名匹配的供应商，金额自动填入 |
| salary_payment | 创建付款单 | 付款单 | DRAFT | 关联员工档案（按"工资"关键词提取的对方户名匹配），金额自动填入 |
| internal_transfer | 创建银行转账单 | 银行转账单 | DRAFT | 对方账户从流水识别，不涉及损益 |

确认后创建的单据标记来源为 `FROM_BANK_TXN`，出纳可在列表页筛选查看。

### FR-BANK-06: 凭证自动生成

对不需要经过业务单据的简单业务类型，确认后直接生成凭证草稿：

| 分类 | 借方科目 | 贷方科目 |
|:---|:---|:---|
| bank_fee | 6602.01 财务费用-手续费 | 1002 银行存款 |
| interest_income | 1002 银行存款 | 6602.02 财务费用-利息收入(红字) |
| tax_payment | 2221 应交税费-各明细 | 1002 银行存款 |
| social_security | 2211 应付职工薪酬-社保 | 1002 银行存款 |
| insurance_fee | 6602.06 管理费用-保险费 | 1002 银行存款 |

凭证状态为 DRAFT，进入总账待审核列表。科目映射通过 `t_voucher_template` 由财务经理配置。
