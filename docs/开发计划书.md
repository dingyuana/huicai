# 慧财财务系统开发计划书

## 一、项目概述

### 1.1 项目背景
慧财财务是一款基于 Web 的企业财务管理系统，覆盖企业财务核算全生命周期，包括基础数据、业务单据、总账、出纳、固定资产、往来、税务、预算、报表分析等核心模块。

### 1.2 技术架构
- **后端**：Spring Boot 3.2.5 + MyBatis-Plus
- **前端**：Vue 3 + Element Plus + ECharts
- **数据库**：PostgreSQL 16 + pgvector + pg_trgm
- **缓存**：Redis 7
- **消息队列**：RabbitMQ（AI 任务）
- **文件存储**：MinIO
- **AI 服务**：Python 3.11 + FastAPI
