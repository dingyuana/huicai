## 一、功能→菜单→角色映射

### 当前 7 个一级菜单结构

```
首页
基础数据   → 会计科目 / 会计期间 / 常用摘要 / 客商档案 / 分类规则 / 系统参数 / 凭证类型
财务核心   → 凭证管理 / 凭证模板 / 账簿查询 / 期末结账 / 期初建账 / 结转向导
业务单据   → 业务单据 / 银行账户 / 银行日记账 / 银行对账单 / 银行对账 / 现金日记账 / 票据管理 / 核销工作台 / 费用报销
税务发票   → 进项发票 / 销项发票 / 增值税计算
固定资产   → 资产类别 / 资产卡片 / 折旧计提 / 资产处置 / 资产盘点
报表中心   → 科目余额表 / 资产负债表 / 利润表 / 现金流量表
```

### 6 项 P0 功能归属

| 序号 | 功能 | 所属菜单 | 所属页面 | 交互类型 |
|------|------|---------|---------|---------|
| F-01 | 科目批量导入 + 模板下载 | 基础数据 | 会计科目 | 弹窗 + 文件上传 |
| F-02 | 客户/供应商批量导入 | 基础数据 | 客商档案 | 弹窗 + 文件上传 |
| F-03 | 凭证 Excel 导出 | 财务核心 | 凭证管理 | 按钮 → 文件下载 |
| F-04 | 账龄分析表 Excel 导出 | 业务单据 | 核销工作台 → 新增「账龄分析」Tab | 页面 Tab + 导出按钮 |
| F-05 | 余额调节表 | 业务单据 | 银行对账 → 新增「余额调节表」Tab | 页面 Tab + 导出按钮 |
| F-06 | 全量报表 Excel 导出 | 报表中心 | 各报表页面 | 按钮 → 文件下载 |

### 角色权限定义

| 角色 | 编码 | 说明 | 可访问的 P0 新增功能 |
|------|------|------|-------------------|
| 系统管理员 | ADMIN | 系统配置、用户管理 | 全部 |

| 出纳 | CASHIER | 资金、银行、票据 | F-05 |
| 业务员 | OPERATOR | 单据录入、发票 | F-02 |

## 二、实施顺序（按依赖关系）

```
F-01 科目批量导入  ─┐
F-02 客商批量导入  ─┤  (独立，无依赖)
F-03 凭证导出      ─┤
                    │
F-06 报表导出      ─┘  (依赖通用导出框架)

F-04 账龄分析导出  ─┐  (依赖账龄分析页面)
F-05 余额调节表    ─┘  (依赖银行对账页面)
```

**建议顺序**：F-01 → F-02 → F-03 → F-06 → F-04 → F-05

## 三、角色权限初始化

### 系统预置角色（已有 + 新增）

| 角色 | 已有 | 说明 |
|------|------|------|
| 管理员 (ADMIN) | ✅ 已有 | 自动拥有全部权限 |
| 财务主管 | ❌ 新增 | 需在 V97 迁移中增加 |
| 会计 | ❌ 新增 | 需在 V97 迁移中增加 |
| 出纳 | ❌ 新增 | 需在 V97 迁移中增加 |
| 业务员 | ❌ 新增 | 需在 V97 迁移中增加 |

### 权限分配方式

- 后端：通过 `t_role_menu` 表控制菜单可见性 + `t_role_permission` 控制按钮级权限
- 前端：`v-permission` 指令 + `authStore.hasPermission(perm)` 控制按钮显示
