# 银行流水智能分类（LLM语义层）执行计划

**目标：** 在现有规则引擎和兜底启发式之间插入 LLM 语义分类层，完成"规则→LLM→兜底"三层架构。
**架构：** 规则命中→直接返回；规则未命中→发起 LLM 异步分类任务（AiTaskService）→等待结果写入→低置信度标记待审；LLM 调用失败→降级兜底。
**技术栈：** Spring Boot + MyBatis-Plus + RabbitMQ（AiTaskService 已有）+ NvidiaAiService（LLM 调用）

**关联需求：** 银行流水智能分类（2026-08-04 需求探索产出）
**风险等级：** 🟡中（涉及状态流转和异步任务，但不涉及金额计算）

### 微循环 3: AiClassificationService 接口 + 实现（核心）

**风险等级：** 🔴高（涉及异步任务创建 + AI 调用 + 结果解析 + 降级逻辑）
**契约：**
- 规则未命中时调用 `classify(statementId)` 返回 `AiTaskEntity`（状态 PENDING）
- LLM 返回结果后 `applyResult(taskId, response)` 写入流水分类
- LLM 调用失败时自动降级为兜底分类，标记 task FAILED
- 每条分类记录 `reasoning` 写入 `outputData`（可追溯）

**文件：**
- 创建：`backend/src/main/java/com/huicai/base/ai/service/AiClassificationService.java`
- 创建：`backend/src/main/java/com/huicai/base/ai/service/impl/AiClassificationServiceImpl.java`

```java
// AiClassificationService.java
package com.huicai.base.ai.service;

import com.huicai.base.ai.entity.AiTaskEntity;

public interface AiClassificationService {
    /**
     * 发起 LLM 分类任务（规则未命中时调用）。
     * @param statementId 流水 ID
     * @return 创建的 AiTaskEntity（状态 PENDING）
     */
    AiTaskEntity classify(Long statementId);

    /**
     * 应用 LLM 返回结果到流水记录。
     * @param taskId    AI 任务 ID
     * @param response  分类结果
     */
    void applyResult(Long taskId, AiClassificationService.Response response);

    /**
     * LLM 调用失败时降级为兜底分类。
     */
    void fallback(Long taskId, String errorMessage);

    record Response(
            String classification,
            java.math.BigDecimal confidence,
            String reasoning
    ) {}
}
```

实现关键点：
- `classify()` 组装 `AiClassificationRequest`，调用 `AiTaskService.createAndDispatch(taskType="BANK_CLASSIFY", bizType="BANK_STATEMENT", bizId=statementId, inputData=map)`
- `applyResult()` 解析 response → 写入流水 `classification` + `ruleId=null` + `aiBusinessScene="AI:" + classification` + `aiConfidence=(int)confidence` + `aiSuggestedAction`（confidence<70 时设为"manual_confirm"）+ 记录 `AiFeedbackLog`
- `fallback()` 调用 `FallbackHeuristicService.classify()` → 写入流水 + 标记 task FAILED

```java
// AiClassificationServiceImpl.java（关键片段）
package com.huicai.base.ai.service.impl;

import cn.hutool.core.util.StrUtil;
import com.baomidou.mybatisplus.core.conditions.query.LambdaQueryWrapper;
import com.huicai.base.ai.dto.AiClassificationRequest;
import com.huicai.base.ai.dto.AiClassificationResponse;
import com.huicai.base.ai.entity.AiFeedbackLogEntity;
import com.huicai.base.ai.service.AiClassificationService;
import com.huicai.base.ai.service.AiFeedbackLogService;
import com.huicai.base.ai.service.AiTaskService;
import com.huicai.base.ai.service.NvidiaAiService;
import com.huicai.base.business.constant.BankClassification;
import com.huicai.base.business.entity.BankStatementEntity;
import com.huicai.base.business.mapper.BankStatementMapper;
import com.huicai.base.business.mapper.ClassificationRuleMapper;
import com.huicai.sme.cash.service.impl.FallbackHeuristicService;
import lombok.RequiredArgsConstructor;
import lombok.extern.slf4j.Slf4j;
import org.springframework.stereotype.Service;

import java.math.BigDecimal;
import java.time.LocalDateTime;
import java.util.Map;
import java.util.regex.Matcher;
import java.util.regex.Pattern;

@Slf4j
@Service
@RequiredArgsConstructor
public class AiClassificationServiceImpl implements AiClassificationService {

    private static final Pattern JSON_PATTERN =
            Pattern.compile("\\{[\\s\\S]*\"classification\"[\\s\\S]*\\}", Pattern.DOT_ALL);

    private final AiTaskService aiTaskService;
    private final NvidiaAiService nvidiaAiService;
    private final BankStatementMapper bankStatementMapper;
    private final AiFeedbackLogService feedbackLogService;
    private final FallbackHeuristicService fallbackHeuristicService;

    @Override
    public AiTaskEntity classify(Long statementId) {
        BankStatementEntity stmt = bankStatementMapper.selectById(statementId);
        if (stmt == null) throw new IllegalArgumentException("流水不存在");

        // 合成用户提示词
        String combinedText = StrUtil.join(" ",
                StrUtil.cleanBlank(stmt.getSummary()),
                StrUtil.cleanBlank(stmt.getPurpose()),
                StrUtil.cleanBlank(stmt.getTransactionRemark())
        );
        String direction = deriveDirection(stmt.getTxType());

        AiClassificationRequest request = new AiClassificationRequest();
        request.setStatementId(statementId);
        request.setCombinedText(combinedText);
        request.setCounterAccount(stmt.getCounterAccount());
        request.setDirection(direction);
        request.setAmount(stmt.getAmount());

        String userPrompt = com.huicai.base.ai.constant.ClassificationPromptTemplate.buildUserPrompt(request);

        // 构造任务 input 数据（包含 prompt 用于可追溯）
        Map<String, Object> inputData = Map.of(
                "statementId", statementId,
                "combinedText", combinedText,
                "counterAccount", stmt.getCounterAccount(),
                "direction", direction,
                "amount", stmt.getAmount() == null ? null : stmt.getAmount().toString(),
                "userPrompt", userPrompt
        );

        return aiTaskService.createAndDispatch(
                "BANK_CLASSIFY", "BANK_STATEMENT", statementId, inputData
        );
    }

    @Override
    public void applyResult(Long taskId, Response response) {
        BankStatementEntity stmt = bankStatementMapper.selectById(
                ((AiClassificationRequest) null).getStatementId() // placeholder, use task inputData
        );
        // 从 task inputData 取 statementId
        com.huicai.base.ai.entity.AiTaskEntity task = aiTaskService.getById(taskId);
        Long statementId = extractStatementId(task.getInputData());
        if (statementId == null) {
            log.error("无法从 task 输入提取 statementId, taskId={}", taskId);
            return;
        }

        stmt = bankStatementMapper.selectById(statementId);
        if (stmt == null) return;

        String classification = response.classification();
        // 校验分类值合法性
        if (!isValidClassification(classification)) {
            log.warn("LLM 返回非法分类值: {}, 降级兜底", classification);
            fallback(taskId, "非法分类值: " + classification);
            return;
        }

        BigDecimal confidence = response.confidence();
        int confInt = confidence != null ? confidence.intValue() : 50;

        stmt.setClassification(classification);
        stmt.setRuleId(null);                    // LLM 分类无规则
        stmt.setAiBusinessScene("AI:" + classification);
        stmt.setAiConfidence(confInt);
        stmt.setAiSuggestedAction(confInt < 70 ? "manual_confirm" : null);

        bankStatementMapper.updateById(stmt);

        // 记录反馈日志（可追溯）
        AiFeedbackLogEntity logEntry = new AiFeedbackLogEntity();
        logEntry.setTaskId(taskId);
        logEntry.setBizType("BANK_STATEMENT");
        logEntry.setBizId(statementId);
        logEntry.setOriginalOutput(response.reasoning());
        logEntry.setApplied(true);
        logEntry.setAppliedAt(LocalDateTime.now());
        feedbackLogService.create(logEntry);

        log.info("LLM 分类已应用: statementId={}, classification={}, confidence={}",
                statementId, classification, confInt);
    }

    @Override
    public void fallback(Long taskId, String errorMessage) {
        com.huicai.base.ai.entity.AiTaskEntity task = aiTaskService.getById(taskId);
        if (task == null) return;
        Long statementId = extractStatementId(task.getInputData());
        if (statementId == null) return;

        BankStatementEntity stmt = bankStatementMapper.selectById(statementId);
        if (stmt == null) return;

        FallbackHeuristicService.Result fb = fallbackHeuristicService.classify(
                stmt.getSummary(), deriveDirection(stmt.getTxType())
        );

        stmt.setClassification(fb.getClassification());
        stmt.setRuleId(null);
        stmt.setAiBusinessScene("FB_FALLBACK:" + fb.getMatchedKeyword());
        stmt.setAiConfidence(fb.getPriority() < 10 ? 75 : 50);
        stmt.setAiSuggestedAction(fb.getPriority() < 10 ? null : "manual_confirm");
        bankStatementMapper.updateById(stmt);

        aiTaskService.handleResult(taskId, "FAILED", null, null, errorMessage);

        log.info("LLM 失败降级: statementId={}, classification={}, reason={}",
                statementId, fb.getClassification(), errorMessage);
    }

    private String deriveDirection(String txType) {
        if (txType == null) return null;
        return switch (txType) {
            case "INCOME", "TRANSFER_IN" -> "in";
            case "EXPENSE", "TRANSFER_OUT" -> "out";
            default -> null;
        };
    }

    private boolean isValidClassification(String cls) {
        return cls != null && switch (cls) {
            case BankClassification.BANK_INTEREST_FEE,
                 BankClassification.TAX_WITHHOLDING,
                 BankClassification.SALARY_SOCIAL,
                 BankClassification.BUSINESS_RECEIPT,
                 BankClassification.BUSINESS_PAYMENT,
                 BankClassification.INTERNAL_TRANSFER,
                 BankClassification.FINANCING_INVEST,
                 BankClassification.OTHER_UNKNOWN -> true;
            default -> false;
        };
    }

    private Long extractStatementId(String inputDataJson) {
        // 简单 JSON 解析（可用 Jackson/Hutool）
        return cn.hutool.json.JSONUtil.toBean(inputDataJson,
                cn.hutool.json.JSONObject.class).getLong("statementId", 0);
    }
}
```

## 风险与缓解

| 风险 | 缓解措施 |
|------|---------|
| LLM 调用超时（Nvidia 不稳定） | 设置 10s 超时，失败自动降级兜底 |
| LLM 返回非法 JSON | 正则提取 + try-catch 降级 |
| LLM 返回非法分类值 | 枚举校验 + 降级 |
| 异步任务丢失（RabbitMQ 异常） | AiTaskService 已有容错（下发失败→FAILED） |
| 现有 classifySingle 被误改 | 保持规则命中分支不变，仅扩展 else 分支 |
