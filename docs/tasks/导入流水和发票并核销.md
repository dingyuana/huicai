# 手工测试流程：导入流水和发票并进行核销

## 一、测试概述

### 测试目标
验证慧财财务系统中"流水导入 → 发票导入 → 核销"的完整业务流程是否正常工作。

### 测试范围
| 模块 | 功能 | 页面路径 |
|------|------|---------|
| 银行流水 | 导入银行对账单、分类、确认 | `/finance/bank-statement` |
| 发票管理 | 销售发票导入、预览、确认 | `/finance/sales-invoice/import` |
| 往来核销 | 核销单管理、核销推荐、确认核销 | `/arap/settlement` |
| 核销工作台 | 基于流水的智能核销推荐 | `/arap/reconciliation-workbench` |

### 测试数据准备
- **银行流水 Excel**：包含收入和支出记录
- **销售发票 Excel**：包含客户信息、金额、税额
- **客户主数据**：至少1个客户（用于发票匹配）
- **银行账户**：至少1个银行账户（用于流水导入）

## 三、测试步骤

### 阶段一：基础数据准备

#### 1.1 登录系统
- 打开前端地址 http://129.211.7.254:3001
- 输入账号：admin，密码：admin123
- 点击登录

#### 1.2 确认银行账户存在
- 进入菜单：系统管理 → 基础设置 → 银行账户
- 确认至少存在1个银行账户（如：中国银行 622202...）
- 如不存在，新增一个测试账户

#### 1.3 确认客户存在
- 进入菜单：往来管理 → 客户管理
- 确认至少存在1个客户（如：测试客户A）
- 记录客户名称和税号（用于发票匹配）

---

### 阶段二：导入银行流水

#### 2.1 进入银行对账单页面
- 进入菜单：财务核心 → 银行对账单

#### 2.2 导入流水文件
- 点击「导入对账单」按钮
- 选择准备好的银行流水 Excel 文件
- 点击「下一步: 预览」

#### 2.3 预览导入数据
| 检查项 | 预期结果 |
|--------|---------|
| 总行数 | 与文件一致 |
| 有效行数 | 大于0 |
| 失败行数 | 0（或有明确错误提示） |
| 数据预览 | 显示日期、方向、金额、对方、摘要 |

#### 2.4 确认导入
- 点击确认导入按钮
- 等待导入完成
- 检查列表中是否显示新导入的流水记录

#### 2.5 流水分类
- 选择一条未分类的流水
- 点击「分类」按钮
- 选择分类类型（如：`business_receipt` 业务收款）
- 确认分类成功

#### 2.6 确认流水
- 选择已分类的流水
- 点击「确认」按钮
- 确认状态变为"已确认"

---

### 阶段三：导入销售发票

#### 3.1 进入销售发票导入页面
- 进入菜单：财务核心 → 销售发票 → 导入

#### 3.2 上传发票文件
- 拖放或选择销售发票 Excel 文件
- 点击「下一步: 预览」

#### 3.3 预览发票数据
| 检查项 | 预期结果 |
|--------|---------|
| 总行数 | 与文件一致 |
| 有效行数 | 大于0 |
| 已有记录 | 显示已存在的发票数量 |
| 失败行数 | 0（或有明确错误提示） |
| 数据预览 | 显示发票号、购方名称、日期、金额、税额 |

#### 3.4 确认导入
- 点击确认导入按钮
- 等待导入完成
- 检查系统是否自动创建了：
  - 应收业务单据（草稿状态）
  - 收入确认凭证（草稿状态）
  - 客户匹配是否正确

---

### 阶段四：往来核销

#### 4.1 通过核销工作台核销（推荐方式）

##### 4.1.1 进入核销工作台
- 进入菜单：往来管理 → 核销工作台
- 选择银行账户
- 筛选已确认的业务收款流水

##### 4.1.2 使用核销推荐
- 找到一条已确认的收款流水
- 点击「核销推荐」按钮
- 等待系统匹配推荐单据

##### 4.1.3 确认推荐结果
| 检查项 | 预期结果 |
|--------|---------|
| 匹配单据 | 显示对应的应收单据/发票 |
| 原始金额 | 与发票金额一致 |
| 未核销金额 | 与发票未核销部分一致 |
| 推荐核销金额 | 默认等于未核销金额 |

##### 4.1.4 执行核销
- 选择推荐的单据
- 输入核销金额（可部分核销）
- 点击确认核销
- 检查核销状态变为"已确认"

#### 4.2 通过核销单管理核销（手动方式）

##### 4.2.1 进入往来核销页面
- 进入菜单：往来管理 → 往来核销

##### 4.2.2 新增核销单
- 点击「新增核销」按钮
- 选择核销类型：应收核销
- 选择客户
- 选择要核销的单据（发票/应收单）
- 输入核销金额
- 保存草稿

##### 4.2.3 确认核销单
- 在核销单列表中找到刚创建的核销单
- 点击「确认」按钮
- 检查状态变为"已确认"

---

### 阶段五：验证核销结果

#### 5.1 检查核销日志
- 在往来核销页面切换到「核销日志」标签
- 筛选来源类型：银行流水
- 确认存在核销记录

#### 5.2 检查单据状态
- 进入应收管理页面
- 查看被核销的单据
- 确认单据的核销金额已更新
- 确认未核销金额减少

#### 5.3 检查凭证生成
- 进入凭证管理页面
- 确认核销单确认后是否自动生成了凭证
- 如配置了自动生成，检查凭证状态

## 七、异常测试场景

| 场景 | 操作 | 预期结果 |
|------|------|---------|
| 重复导入 | 导入相同的流水/发票 | 系统提示已存在，跳过或更新 |
| 无效文件格式 | 上传非Excel文件 | 系统拒绝并提示错误 |
| 数据格式错误 | Excel中金额为文本格式 | 导入失败，显示错误原因 |
| 客户不存在 | 发票购方名称未匹配到客户 | 提示新建客户或跳过 |
| 金额不匹配 | 核销金额大于未核销金额 | 系统拒绝并提示 |
| 权限不足 | 非admin用户操作 | 提示权限不足 |
