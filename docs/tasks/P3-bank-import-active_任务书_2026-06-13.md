### Step 3：R1 改触发时机（D1 修复）

**位置**：`BankStatementServiceImpl.importFromCsv` + `importFromExcel` 末尾

**当前**（伪代码）：
```java
public ImportResult importFromCsv(...) {
    // 1. 解析 CSV
    // 2. 批量 insert
    return result;
}
```

**改为**：
```java
public ImportResult importFromCsv(...) {
    // 1. 解析 CSV
    // 2. 批量 insert
    // 3. 【新增】对每条新插入的流水，调用 autoGenerateService.autoGenerate(stmt.id, userId)
    //    - A 类：直接生成凭证草稿
    //    - B 类：生成业务单据草稿 + 凭证草稿
    //    - C 类：log + 留在 review_status=UNCONFIRMED 待处理池
    return result;
}
```

**关键设计决策**：
- 全部在 `@Transactional` 内（导入失败则生单全部回滚）
- A 类 → 真"主动"（直接生成 DRAFT 凭证，但 docStatus=0 等人审）
- B 类 → "半主动"（生成 DRAFT 业务单据 + DRAFT 凭证，待人审）
- C 类 → "不动"（留在 review_status=UNCONFIRMED，进待处理池 —— 走 Step 4 工作台）
- **导入返回 result 需扩展**：`activeVouchers` (A 类生成的) + `activeDocs` (B 类生成的) + `pending` (C 类待处理)
