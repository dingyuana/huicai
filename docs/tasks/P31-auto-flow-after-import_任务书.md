# P31: 发票导入后自动全流程处理 (审核+生单+生凭证)

## 目标
销售发票批量导入后，系统自动完成：发票审核 → 生成应收/应付单 → 审核业务单 → 生成凭证，人工仅需最后一步凭证审核。
**硬约束**：人必须是凭证审核的最终负责人，不能跳过凭证审核；异常情况自动告警通知人工处理。

## 边界
- **配置开关**: `invoice.auto_flow_after_import` (默认 `false`，避免影响现有流程)
- **触发时机**: 导入批次确认完成后立即触发（异步执行，不阻塞导入返回）
- **失败重试**: 失败后自动重试 1 次（处理偶发科目匹配缓存问题）
- **告警方式**: 复用站内信接口，处理完成后发送结果通知

## 流程对比
| 场景 | 当前 | 优化后 |
|------|------|--------|
| 100张发票无异常 | 6步、5-10分钟 | 2步、1分钟 (导入→凭证页审核) |
| 100张发票5张异常 | 6步、5-10分钟 | 2步、1分钟 (导入→凭证页审核95张→失败明细处理5张) |

## 实现方案

### 后端
1. **配置项**: `application.yml` 新增 `invoice.auto-flow-after-import: false`
2. **异步服务**: `InvoiceImportPostProcessService#postProcess(batchId, userId)`
   - 批量审核发票 (调 `OutputInvoiceService#batchApprove`)
   - 批量生成应收单 (调 `BusinessDocService#batchGenerateFromInvoices`)
   - 批量提交+审核业务单
   - 批量生成凭证
   - 捕获每步异常，失败明细写入 `t_invoice_import_log`
3. **触发点**: `SalesInvoiceImportService#confirmImport` 完成后调异步服务
4. **告警**: 处理完成后调 `MessageCenterService` 发送站内信

### 前端
- 导入结果页新增「失败明细」折叠面板
- 显示失败发票号 + 失败原因
- 站内信收件箱集成

## 验收
- [ ] 配置项默认关闭，开启后导入发票触发全流程
- [ ] 异步执行不阻塞导入接口返回 (< 1秒)
- [ ] 异常情况下，导入结果页显示失败明细，站内信收到通知
- [ ] 人工凭证审核流程不变，凭证生成后状态为 `PENDING_REVIEW`
