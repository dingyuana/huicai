## 验收标准（BDD）

### 场景 1：资金计划编制与审核执行
- **Given** 财务部编制了下月资金计划（按部门分类），总金额 500 万元，计划处于 DRAFT 状态
- **When** 财务主管审核通过资金计划，计划进入执行阶段
- **Then** 资金计划状态流转为 DRAFT -> AUDITED -> EXECUTING，各部门可按计划额度发起资金支付申请

### 场景 2：资金计划超支拦截
- **Given** 销售部本月资金计划额度为 50 万元，已执行 48 万元
- **When** 销售部提交一笔金额为 5 万元的资金支付申请
- **Then** 系统检测到该申请将使部门执行总额（53 万元）超过计划额度（50 万元），返回错误码 20304，拒绝该申请

### 场景 3：票据正常背书转让
- **Given** 企业持有一张面额 100 万元的银行承兑汇票，票据状态为 PENDING，未进行过任何操作
- **When** 用户选择该票据并进行背书转让操作，填写被背书人信息
- **Then** 票据状态更新为 IN_USE，生成背书转让凭证（DRAFT），票据台账记录更新

### 场景 4：已使用票据禁止重复操作
- **Given** 某张票据已被用于贴现操作，当前状态为 DISCOUNTED
- **When** 用户尝试对该票据再次发起托收操作
- **Then** 系统检测到票据已使用，返回错误码 20305，拒绝重复操作，提示该票据已被贴现

### 场景 5：票据贴现计算异常
- **Given** 一张面额 100 万元的票据，贴现率为 3.5%，贴现天数输入为 -5（负数）
- **When** 用户发起贴现计算请求
- **Then** 系统检测到贴现天数不合法，返回错误码 20306，提示贴现天数必须为正数，不生成贴现凭证
