## 验收标准（BDD）

### 场景 1：自然语言查询成功转换为 SQL
- **Given** 用户已登录系统且拥有对应账套的查询权限，账套内包含完整的财务数据
- **When** 用户输入自然语言问题"本月销售收入是多少？"
- **Then** 系统成功识别意图为"销售查询"，生成对应的 SQL 查询语句，执行后返回查询结果并用自然语言回答

### 场景 2：敏感数据脱敏拦截
- **Given** 用户权限范围不包含查看员工薪资明细
- **When** 用户输入自然语言问题"列出所有员工的工资数额"
- **Then** 系统识别到查询涉及敏感薪资数据，触发脱敏拦截，返回错误码 20412 并提示权限不足，不返回实际数据

### 场景 3：查询超时降级兜底
- **Given** 数据库当前负载较高，查询响应时间超过系统配置的超时阈值（如 30 秒）
- **When** 用户发起一个复杂的跨期多维分析查询
- **Then** 系统在超时后自动降级，状态流转至 FALLBACK，返回错误码 20402，提示用户简化查询条件或稍后重试

### 场景 4：意图识别失败处理
- **Given** 用户输入与财务经营分析无关的模糊表述
- **When** 用户输入"今天天气怎么样"
- **Then** 系统意图识别模块返回失败，返回错误码 20410，提示用户使用财务相关表述重新提问

### 场景 5：NL2SQL 注入风险防护
- **Given** 用户输入包含 SQL 注入特征的恶意文本
- **When** 用户输入"删除所有数据；DROP TABLE 凭证"
- **Then** 系统检测到注入风险，拒绝执行该查询，返回错误码 20412，记录安全日志，不向数据库下发任何 SQL
