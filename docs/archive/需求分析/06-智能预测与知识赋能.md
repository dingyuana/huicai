## 1. 业务概述

第三阶段打造主动式、预见型财务系统，从"事后记录"迈向"事前预测"。通过现金流预测、信用管理、自动月末结账检查、跨系统对账、电子档案检索和知识问答，实现财务整体人效提升 3-5 倍。

## 2. 功能需求

### FR-PREDICT-01: 现金流预测与资金预警

**1.1 智能预测**

| 需求 | 说明 |
|:---|:-----|
| FR-PREDICT-01.1 | 基于应收应付周期、历史回款规律、销售计划，预测未来 30/60/90 天现金流 |
| FR-PREDICT-01.2 | 使用时间序列模型（Prophet / ARIMA）训练预测 |
| FR-PREDICT-01.3 | 预测结果以图表展示：每日/每周现金余额趋势线 |
| FR-PREDICT-01.4 | 展示预测置信区间（阴影区域）|
| FR-PREDICT-01.5 | 每月自动更新模型，滚动预测 |

**1.2 资金预警**

| 需求 | 说明 |
|:---|:-----|
| FR-PREDICT-01.6 | 预测余额低于安全线（可配置，如月均支出的 2 倍）时自动通知 |
| FR-PREDICT-01.7 | 大额支付集中到期提醒（单日累计支付 > 阈值）|
| FR-PREDICT-01.8 | 贷款到期/还款日前 N 天自动提醒 |
| FR-PREDICT-01.9 | 预警通过系统消息 + 飞书/企业微信推送 |

**2.2 逾期催收建议**

### FR-PREDICT-03: 自动月末结账检查

**3.1 一键结账体检**

月度结账前自动执行全面检查，逐项列出待处理事项：

| 检查项 | 说明 |
|:---|:-----|
| 凭证完整性 | 当月所有凭证是否已审核、已记账 |
| 断号检查 | 凭证编号是否存在断号 |
| 银行余额调节表 | 自动生成余额调节表，检查未达账项是否合理 |
| 暂估与到票核对 | 暂估入库单是否已收到发票 |
| 折旧摊销完整性 | 固定资产折旧是否已全部计提 |
| 科目余额方向 | 检查科目余额方向是否异常（如应收账款出现贷方余额）|
| 损益结转 | 损益类科目余额是否已全部结转至本年利润 |
| 试算平衡 | 资产=负债+所有者权益 |

**3.2 问题清单**

- 每个检查项展示状态（✅通过/⚠️警告/❌不通过）
- 不通过项展示具体问题数据，引导会计逐一处理
- 仅全部检查项通过后才允许执行结账操作
- 支持财务经理强制结账（高风险操作，需记录原因）

### FR-PREDICT-05: 电子会计档案智能检索

**5.1 多维标签归档**

| 需求 | 说明 |
|:---|:-----|
| FR-PREDICT-05.1 | 凭证、发票、合同、银行回单等自动分类归档 |
| FR-PREDICT-05.2 | AI 自动生成业务标签（如"设备采购/北京华联/2026Q1"）|
| FR-PREDICT-05.3 | 支持按凭证号、发票号、金额、期间、对方名称、标签等维度检索 |

**5.2 自然语言检索**

| 需求 | 说明 |
|:---|:-----|
| FR-PREDICT-05.4 | 用户可用自然语言检索档案（如"找下去年与 A 公司的设备采购合同及对应发票"）|
| FR-PREDICT-05.5 | 检索结果以列表展示，支持预览和下载 |
| FR-PREDICT-05.6 | 利用 pgvector 做语义相似度检索 |

**5.3 审计支持**

| 需求 | 说明 |
|:---|:-----|
| FR-PREDICT-05.7 | 审计人员可针对某张凭证提问，系统自动关联附件、审批流 |
| FR-PREDICT-05.8 | 生成业务背景说明（谁、何时、为什么做这笔凭证）|
| FR-PREDICT-05.9 | 审计轨迹全程可追溯 |

### FR-PREDICT-06: 财务知识问答与 Copilot

**6.1 制度问答机器人**

| 需求 | 说明 |
|:---|:-----|
| FR-PREDICT-06.1 | 员工可查询报销标准、流程要求（如"出差住宿标准是多少"）|
| FR-PREDICT-06.2 | 会计可咨询会计准则应用（如"新租赁准则如何处理"）|
| FR-PREDICT-06.3 | 基于 RAG 架构：财务制度文档 → 嵌入向量库 → 语义检索 → LLM 回答 |

**6.2 智能操作引导（Copilot）**

| 需求 | 说明 |
|:---|:-----|
| FR-PREDICT-06.4 | 在处理复杂业务（如出口退税、新收入准则）时，AI 逐步指导填单 |
| FR-PREDICT-06.5 | 对每个表单字段解释财税原理和填写要求 |
| FR-PREDICT-06.6 | 异常情况推送处理建议 |

**7.1 辅助预算编制**

| 需求 | 说明 |
|:---|:-----|
| FR-PREDICT-07.1 | 基于历史 N 年数据自动推荐各部门/项目预算金额 |
| FR-PREDICT-07.2 | 支持弹性预算：根据业务量自动调整预算额度 |
| FR-PREDICT-07.3 | 预算编制完成后展示对比视图（历史 vs 建议 vs 最终）|

**7.2 实时执行控制**

| 需求 | 说明 |
|:---|:-----|
| FR-PREDICT-07.4 | 费用发生时进行预算检查 |
