## 1. 业务概述

财务报表分析和税务管理是企业财务的高价值工作，传统模式下依赖人工编制分析报告、手动计算税负，费时费力且容易遗漏风险。

本模块通过自然语言查询（NL2SQL）、AI 分析生成以及智能税务管理，将财务人员从重复劳动中解放出来，聚焦于经营分析和管理决策。

---

## 2. 功能需求

### FR-ANALYSIS-01: 自然语言财务分析（NL2SQL）

**1.1 查询方式**

管理层和财务人员可通过日常语言对系统提问，自动转化为数据查询：

| 典型问题 | 预期响应 |
|:---|:---|
| "查询今年上半年各区域毛利率" | 生成按区域分组的毛利率图表 + 文字解释 |
| "本月销售费用比上月增长多少？" | 展示销售费用同比环比数据 + 主要增长科目 |
| "A 客户的应收账款逾期情况" | 列出 A 客户的逾期发票及金额 |
| "去年各季度收入趋势" | 生成折线图 + 季度对比数据 |
| "管理费用超预算的部门" | 列出超预算部门及超支金额 |

**1.2 技术实现**

- 自然语言 → 意图识别 → 转换为 SQL 查询
- 财务指标公式预置在系统中（毛利率=收入-成本/收入等）
- 查询结果自动生成 ECharts 图表
- 大模型生成分析报告的叙述性文字

### FR-ANALYSIS-02: 月度经营分析自动生成

- 每月初自动提取上月的关键财务指标
- 生成标准分析报告模板：收入分析/成本分析/费用分析/利润分析/现金流分析
- 自动计算同比/环比增长率
- 利用大模型生成叙述性分析结论及改进建议
- 报告支持导出 PDF/Excel

### FR-ANALYSIS-03: 财务指标预警

- 预置常用财务指标公式：毛利率/净利率/流动比率/资产负债率/ROE 等
- 指标超阈值自动通知相关责任人
- 预警阈值可由财务经理配置

## 3. 智能税务管理

### FR-TAX-01: 税负测算与预测

| 需求 | 说明 |
|:---|:-----|
| FR-TAX-01.1 | 根据当前账务数据自动测算应缴增值税、企业所得税 |
| FR-TAX-01.2 | 展示税负率（实际已缴 / 应缴），与行业平均税负率对比 |
| FR-TAX-01.3 | 税负波动预警：月度/季度税负率与历史同期偏差超过阈值时自动提醒 |

### FR-TAX-02: 进项认证优化

- 结合资金流（银行存款余额）与税负目标
- 建议本期应认证的进项税额范围
- 避免产生大额留抵或大额应缴

### FR-TAX-03: 税务风险扫描

| 扫描项 | 说明 |
|:---|:-----|
| 进销项匹配 | 检查进项发票与销项发票的商品/服务是否匹配，防范虚开风险 |
| 税负率预警 | 税负率低于行业预警值或波动超过 30% 时预警 |
| 发票异常 | 同一供应商连续开票金额异常、夜间开票、节假日开票等 |
| 申报一致性 | 纳税申报表数据与账务数据的一致性校验 |

### FR-TAX-04: 税金计提与凭证生成

- 期末自动按期间计提各税种
- 计提后自动生成凭证草稿（借：6403 税金及附加 / 贷：2221 应交税费）
- 计提结果提交财务经理审核，审核通过后凭证生效

### FR-TAX-05: 出口退税底稿（远期）

- 匹配报关单、发票、收汇水单
- 自动生成出口退税申报底稿

## 4. 合同应付智能管理

### FR-CONTRACT-01: 条款提取

- 上传采购合同/服务协议 PDF 后，AI 自动提取关键条款：
  - 付款节点（预付/到货/验收/质保）
  - 各节点付款比例及金额
  - 付款条件（发票要求、验收标准）
  - 违约责任与质保条款

### FR-CONTRACT-02: 应付计划生成

- 根据提取的付款条款自动创建应付日程
- 到期前 N 天自动提醒相关责任人安排付款
- 付款时自动关联对应的采购发票

### FR-CONTRACT-03: 发票与合同校验

- 采购发票导入时，自动匹配对应的采购合同
- 校验发票金额、税率、商品是否与合同一致
- 差异自动标记，提示财务人员核查
