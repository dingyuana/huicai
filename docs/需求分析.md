**SME**：工资薪酬待实现，其余已实现

- 移动端原生App
- NL2SQL 经营分析

## 3. 非功能需求

| 需求 | 指标 | 说明 |
|------|------|------|
| 金额精度 | 小数点后2位 | BigDecimal + NUMERIC(18,2) |
| 响应时间 | 列表查询<2s，操作<1s | 索引优化，Redis缓存 |
| 并发 | 支持50人同时操作 | 单体部署，无需分布式 |
| 可用性 | 99.5% | 单体部署，关键数据备份 |
| 审计 | 所有操作可追溯 | AOP拦截+jsonb快照 |
| 数据隔离 | 组织级+租户级 | MyBatis拦截器注入SQL条件 |

## 4. 验收标准

### 4.1 底座验收

- [ ] 科目树形CRUD通过
- [ ] 凭证6态状态机所有转换通过
- [ ] 红冲前向+反向级联通过
- [ ] 期末结账前置检查通过
- [ ] 三大报表数据正确
- [ ] RBAC权限控制有效

### 4.2 SME 验收

- [ ] 发票导入→审核→凭证全流程可用
- [ ] 银行流水→分类→核销全流程可用
- [ ] 固定资产折旧计算正确
- [ ] 费用报销→审批→打款流程可用
- [ ] 预算三级控制（WARN/APPROVE/BLOCK）有效
- [ ] 工资表计算→审核→凭证生成可用
- [ ] 所有审核点人工完成

### 4.3 Agency 验收

- [ ] 多客户账套切换+数据隔离有效
- [ ] 批量导入/审核/结账/报表可用
- [ ] 客户CRM（合同+续费提醒）可用
- [ ] 移动端审批（列表+同意/驳回）可用
