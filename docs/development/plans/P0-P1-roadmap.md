## 一、P0 模块（竞品标配，小微企业刚需）

### P0-1: 工资薪酬模块
**REQ-2026-160** | **SPEC-P143**（待编制）

| 项目 | 内容 |
|------|------|
| 现状 | `SalaryList.vue` 仅占位页，无后端实现 |
| 对标 | 金蝶精斗云·工资管理 / 畅捷通好会计·工资模块 |
| 核心功能 | ①工资表管理（员工、岗位、薪资项目）②个税自动计算（累计预扣法）③工资凭证自动生成 ④员工自助查询 |
| 实施难度 | 中 |
| 预估工作量 | 2-3 周 |
| 前置依赖 | 无（独立模块） |
| 优先级 | P0 |

**关键决策项**：
- D-1: 个税计算采用累计预扣法（符合个税法规定）
- D-2: 工资凭证自动生成走现有凭证流程（post/unpost/batchReviewPost）
- D-3: 员工自助查询通过小程序/H5（暂不做原生APP）
- D-4: 薪资项目可配置（固定工资、绩效、津贴、扣款等）

### P0-2: 固定资产模块完善
**REQ-2026-161** | **SPEC-P144**（待编制）

| 项目 | 内容 |
|------|------|
| 现状 | `AssetController` 有基础台账，但无折旧凭证联动、无资产卡片管理 |
| 对标 | 金蝶精斗云·固定资产 / 畅捷通好会计·固定资产 |
| 核心功能 | ①资产卡片管理（原值、折旧方法、使用年限）②折旧计提（直线法/双倍余额递减法/年数总和法）③折旧凭证自动生成 ④资产变动（新增/减少/调整）⑤与结账流程联动 |
| 实施难度 | 中 |
| 预估工作量 | 1-2 周 |
| 前置依赖 | 现有凭证流程已支持结转步骤 DEPR |
| 优先级 | P0 |

**关键决策项**：
- D-1: 折旧方法支持直线法（默认）、双倍余额递减法、年数总和法
- D-2: 折旧凭证生成走现有 `CarryoverSequenceServiceImpl` 的 DEPR 步骤
- D-3: 资产卡片复用现有 `AssetEntity`，补充缺失字段
- D-4: 资产变动生成调整凭证（不修改原折旧记录）

## 二、P1 模块（合规要求，提升体验）

### P1-1: 税务申报对接
**REQ-2026-162** | **SPEC-P145**（待编制）

| 项目 | 内容 |
|------|------|
| 现状 | 进项/销项发票管理已完整，但无一键报税、无税负测算 |
| 对标 | 金蝶精斗云·智能税务 / 畅捷通好会计·一键报税 |
| 核心功能 | ①增值税申报（进项/销项汇总、应纳税额计算）②企业所得税预缴申报 ③税负率分析 ④申报表导出（Excel/PDF）⑤对接电子税务局 API（可选） |
| 实施难度 | 高 |
| 预估工作量 | 2-4 周 |
| 前置依赖 | 发票管理模块已完整；电子税务局 API 接入需申请 |
| 优先级 | P1 |

**关键决策项**：
- D-1: 首期仅提供申报表导出功能（不强制对接 API）
- D-2: 增值税申报表按现行税率（13%/9%/6%/0%）自动计算
- D-3: 税负率预警阈值可配置（默认 3%）
- D-4: 后续迭代支持电子税务局直连（需申请接口权限）

### P1-2: 费用报销模块
**REQ-2026-163** | **SPEC-P146**（待编制）

| 项目 | 内容 |
|------|------|
| 现状 | 无报销流程 |
| 对标 | 金蝶精斗云·费用报销 / 畅捷通好会计·费控管理 |
| 核心功能 | ①报销申请（差旅费、业务费、办公费）②审批流（多级审批可配置）③报销凭证自动生成 ④费用分析报表 |
| 实施难度 | 中 |
| 预估工作量 | 1-2 周 |
| 前置依赖 | 凭证流程已完整；审批流可复用现有 `AgencyService` |
| 优先级 | P1 |

**关键决策项**：
- D-1: 审批流复用现有代理派工流程（`t_agency_assignment`）
- D-2: 报销凭证自动生成走现有 `VoucherServiceImpl.post()`
- D-3: 费用科目预设（差旅费、业务招待费、办公费等）
- D-4: 首期不做移动端审批（桌面端完成即可）

## 六、风险评估

| 风险 | 影响 | 缓解措施 |
|------|------|---------|
| 个税政策变化 | 计算逻辑需更新 | 个税计算参数化，阈值/公式可配置 |
| 电子税务局 API 变更 | 对接功能失效 | 首期不强制对接，仅导出功能 |
| 审批流复杂度 | 开发延期 | 复用现有代理派工流程，不做独立审批引擎 |
| 工资数据敏感性 | 安全风险 | 行级权限控制（`EnterpriseWriteGuard`） |
