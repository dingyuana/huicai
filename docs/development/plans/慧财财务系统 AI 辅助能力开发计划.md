## 一、定位

**AI 不是独立的一层，而是横切辅助能力，叠加在现有 Java 模块之上。**

核心原则：
- **确定性操作**（凭证过账、结账、折旧、核销执行）→ Java 状态机控制，AI 不介入
- **非确定性操作**（科目推荐、异常检测、分类匹配、语义理解）→ AI 辅助，结果必须人工确认后落库
- **AI 输出 = 建议**，永远不自动应用到财务数据
- **不引入新基础设施**（不引入 ClickHouse、Nacos、K8s、NebulaGraph）

## 五、技术栈（实际使用）

| 技术 | 用途 | 状态 |
|------|------|------|
| Spring Boot 3.x | 后端业务底座 | ✅ 已有 |
| PostgreSQL 16 + pgvector | 向量检索 | ✅ 已有 |
| Redis 7 | 缓存、分布式锁 | ✅ 已有 |
| RabbitMQ | 异步 AI 任务 | ✅ 已有 |
| Python FastAPI | AI 服务 | ✅ 已有 |
| **LangChain** | LLM 调用统一管理 | ❌ 待引入 |
| **LangGraph** | 多步推理编排 | ❌ 待引入（仅 AI 场景） |
| Vue 3 + Element Plus | 前端 | ✅ 已有 |

**不引入的技术：**
- ❌ ClickHouse（当前数据量不需要 OLAP）
- ❌ Microservices / Nacos / Sentinel（单体够用）
- ❌ K8s（Docker Compose 够用）
- ❌ NebulaGraph（不需要关系图谱）
- ❌ 多模型网关（当前单模型够用）

## 六、AI 输出安全机制

| 置信度 | 行为 |
|--------|------|
| ≥ 0.9 | 自动推荐，前端标注"AI 推荐" |
| 0.5 ~ 0.9 | 列出 top-3 候选，人工选择 |
| < 0.5 | 挂起，人工补全，不自动应用 |
