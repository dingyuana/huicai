## 三、分模块开发规划

### ① 销售与收款循环 — 待开发 3 个子模块

**当前状态**：INVOICE_OUT + P34 业务单据 + 核销工作台 + 预收预付 ✅ 已上线

**待开发（SPEC 已完成，待执行）**：

| 子模块 | 编号 | 预估工时 | 说明 |
|--------|------|---------|------|
| **坏账准备计提** | P43 | 12h | 科目1231/6701、计提方案、补提/冲回、自动生成凭证 |
| **账龄分析与逾期预警** | P51 | 12h | 账龄分布表、到期债权表、4级预警 |
| **客户对账与差异处理** | P52 | 15h | 对账单生成、未达账项、差异处理闭环 |

**三者关系**：
```
核销完成 → 客户对账(P52) → 账龄分析(P51) → 坏账计提(P43) → 凭证
                                                      ↑
                                   跳过有差异客户(P52→P43 联动)
```

**建议启动时间**：**2026年Q4**（年底结账前完成即可）

### ⑥ 薪酬与社保循环 — 待启动

**当前状态**：❌ 完全未实现（P0-P3 路线图中列为 P3 远期）

**范围**：考勤数据 → 薪资计算 → 社保公积金 → 个税 → 凭证 → 工资条

**凭证节点**：

| 业务事件 | 借方 | 贷方 |
|---------|------|------|
| 计提工资 | 管理费用/生产成本等 | 应付职工薪酬 |
| 计提社保（企业部分） | 管理费用等 | 应付职工薪酬——社保 |
| 发放工资 | 应付职工薪酬 | 银行存款/其他应付款（代扣个税社保） |
| 缴纳社保公积金 | 应付职工薪酬——社保 | 银行存款 |

**建议启动时间**：P3 远期，当前不优先

## 六、关键结论

1. **6/9 模块已完成**，核心财务体系已具备
2. **当前最急迫的是 P43+P51+P52**（39h，年底结账必备）
3. **薪酬社保是唯一未启动的大模块**（15h，P3 远期）
4. **存货成本 + 多币种 + 员工借款 + 采购三单匹配**均不在范围，无需关注
5. **整体工时剩余约 90h**，其中 43% 是年底结账必须的 3 个 SPEC 开发
