# 年底结账三件套执行计划

> **版本**：V1.0 | **日期**：2026-07-11

---

## 一、执行顺序

```
P51 账龄分析（独立） → P52 客户对账（依赖账龄数据） → P43 坏账计提（依赖两者）
    12h                     15h                           12h
```

**为什么先做 P51**：P52 对账单需要账龄分布，P43 坏账引擎复用 P51 的账龄分析，P52 的差异跳过逻辑是 P43 的前置条件。
