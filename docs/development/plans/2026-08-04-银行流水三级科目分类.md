# 银行流水三级科目分类 执行计划

**目标：** 在规则引擎命中时输出三级科目标签（一级/二级/三级），前端展示完整科目路径。
**架构：** 规则实体 `ClassificationRuleEntity` 新增三级科目字段 → 种子数据补填参考值 → `classifySingle()` 命中时同步写入流水 → 前端列表展示。
**技术栈：** Spring Boot + MyBatis-Plus + PostgreSQL（Flyway）+ Vue

**关联需求：** 银行流水智能分类（2026-08-04 需求探索）
**风险等级：** 🟡中（涉及 DB migration + 两个实体改动 + 服务层同步）

## 方案总览

```
改动前:
  classifySingle() 规则命中 → 写 classification（8类常量）→ 无三级科目

改动后:
  classifySingle() 规则命中 → 写 classification（保持）+ subjectLevel1/2/3
  规则未命中（兜底）→ subjectLevel1/2/3 为空
```

**核心决策：三级科目挂在规则上，不建新映射表。**
理由：科目路径是规则配置的一部分，规则表已有 `debit_subject_id`/`credit_subject_id` 字段（空），再加 3 个 VARCHAR 字段语义清晰、无需 join。

### 微循环 4: BankStatementServiceImpl.classifySingle() 写三级科目

**风险等级：** 🟡中（改动现有业务逻辑）
**契约：**
- 规则命中时：`subjectLevel1/2/3 = rule.subjectLevel1/2/3`

**文件：**
- 修改：`backend/src/main/java/com/huicai/sme/cash/service/impl/BankStatementServiceImpl.java`（`classifySingle()` 方法，规则命中分支内）

在 `stmt.setRuleId(finalRuleId);` 之后、`stmt.setClassification(finalClassification);` 之前或之后加：
```java
// 规则命中时同步写入三级科目（规则未命中/兜底时三字段保持 null）
if (rule != null) {
    stmt.setSubjectLevel1(rule.getSubjectLevel1());
    stmt.setSubjectLevel2(rule.getSubjectLevel2());
    stmt.setSubjectLevel3(rule.getSubjectLevel3());
}
```

**注意：** 兜底分支（`else` 块，`FallbackHeuristicService`）不要写三字段，保持 null。

## 验收 BDD

```
Scenario: 规则命中写入三级科目
  Given 一条种子规则 classification=business_receipt, subjectLevel1=业务收款, subjectLevel2=主营业务收入, subjectLevel3=货款收入
  When 流水摘要含"货款"调用 classifySingle
  Then statement.subjectLevel1 == "业务收款" 且 subjectLevel2 == "主营业务收入" 且 subjectLevel3 == "货款收入"

Scenario: 兜底分类三字段为空
  Given 流水摘要无法命中任何规则
  When 调用 classifySingle
  Then classification == "business_receipt"（兜底方向推断）且 subjectLevel1 == null

Scenario: 已存在流水补分类
  Given 一条已存在流水无三级科目
  When 用户重新调用 classifySingle 并命中规则
  Then subjectLevel1/2/3 被更新为规则值

Scenario: 种子数据三级科目可配置
  Given 用户打开分类规则配置页
  When 编辑"业务收款"规则
  Then 表单展示一级/二级/三级科目输入框，值为参考种子值
```

## 风险与缓解

| 风险 | 缓解措施 |
|------|---------|
| migration 在已有数据上执行 | 新字段默认 NULL，不影响存量流水 |
| `classifySingle()` 改动影响其他逻辑 | 仅在规则命中分支加三字段写入，兜底分支不动 |
| 种子三级科目与实际科目表不一致 | 仅为展示参考值，不强制关联 `t_subject` 主键，用户可自由编辑 |
| 前端列表页面结构未知 | 先读文件确认当前列结构，再决定是新增列还是替换列 |
