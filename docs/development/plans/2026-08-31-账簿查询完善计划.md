## 4. 执行规范（遵守 AGENTS.md）

1. **三步闭环**：每个 T 任务先写 SPEC 草案 → 老丁审核 → 再开发，禁止跳过
2. **TDD-First**：先写测试（Red）→ 确认 FAIL → 实现（Green），核心任务补真实 DB 链路测试
3. **期间过滤铁律**：所有新增账簿查询必须带 period + deleted=0 条件（防再次串账）
4. **金额精度**：BigDecimal + NUMERIC(18,2)
5. **DTO/VO 隔离**：入参 Param、出参 VO，禁止 Map 直出（T10 逐步收敛）
6. **JSONB 字段**：assist_json 读取必须带 `::jsonb` / typeHandler，禁止裸 String 比较
7. **状态机**：本计划只涉及查询侧，不触碰凭证/单据状态机
