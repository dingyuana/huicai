## 实施步骤

### Step 1：补 docker-compose 中间件

新建 `docker-compose.dev.yml`（如已有则补充），加 3 个服务：

```yaml
version: '3.8'
services:
  rabbitmq:
    image: rabbitmq:3.13-management
    container_name: huicai-rabbitmq
    ports:
      - "5672:5672"
      - "15672:15672"
    environment:
      RABBITMQ_DEFAULT_USER: huicai
      RABBITMQ_DEFAULT_PASS: huicai123
    volumes:
      - ./docker/volumes/rabbitmq:/var/lib/rabbitmq
  redis:
    image: redis:7-alpine
    container_name: huicai-redis
    ports:
      - "6379:6379"
  minio:
    image: minio/minio:latest
    container_name: huicai-minio
    ports:
      - "9000:9000"
      - "9001:9001"
    environment:
      MINIO_ROOT_USER: huicai
      MINIO_ROOT_PASSWORD: huicai123
    command: server /data --console-address ":9001"
    volumes:
      - ./docker/volumes/minio:/data
```

启动：
```bash
cd /root/data/disk/huicai
docker compose -f docker-compose.dev.yml up -d
docker ps | grep -E "huicai-(rabbitmq|redis|minio)"
```

### Step 2：应用配置适配

检查 `backend/src/main/resources/application-dev.yml`：
- `spring.rabbitmq.host=127.0.0.1`（如未配则加）
- `spring.redis.host=127.0.0.1`
- `minio.endpoint=http://127.0.0.1:9000`

**关键边界**：**只补缺失配置，不改业务逻辑**。如果 yml 已有 host 配置但缺端口/密码，只补缺失字段。

### Step 3：Spring Boot 启动

```bash
cd /root/data/disk/huicai/backend
./mvnw spring-boot:run -Dspring-boot.run.profiles=dev -Dspring-boot.run.arguments="--server.port=18080" &
# 等 "Started HuicaiApplication"（最多 2 分钟）
# 验证：curl -s http://127.0.0.1:18080/actuator/health | jq .status
# 期望："UP"
```

**若启动失败**：
- RabbitMQ 连接错 → 检查 yml 端口/密码
- Redis 连接错 → 同上
- MinIO 错 → 暂时不强依赖（不阻塞 P1 端到端）
- Bean 循环依赖 → **报具体错，不要乱改**（可能 P1 之前代码就埋了雷）

### Step 4：真跑 5 端点

参考 `docs/tasks/P1-end-to-end-verification_验证报告_2026-06-12.md` 里的脚本，5 端点：

1. `POST /api/finance/bank-statement/import-csv` — 导入 CSV/Excel
2. `POST /api/finance/bank-statement/classify` — 自动分类（调规则引擎）
3. `POST /api/finance/bank-statement/review/{id}` — 出纳确认单条
4. `POST /api/finance/bank-statement/batch-review` — 批量确认
5. `GET /api/finance/bank-statement/page` — 分页查询

每端点 curl 完必须返回 **200 + 业务码 0**，且响应体含期望字段（用 jq 校验）。
