# 项目说明报告

## 一、 项目愿景与战略定位

### 1.1 产品愿景

打造新一代“AI原生业财协同平台”，以算力替代传统人力，重塑中小微企业的财务管理与代账服务生态。让代账机构从“人力密集型劳务工厂”蜕变为“算力驱动的高价值财税智库”，让中小微企业实现合规记账、实时看账与智能决策。

### 1.2 核心定位

采用“一套底层引擎，双端场景赋能”的 B2B2C 架构：

- **面向中小微企业**：提供轻量化的“业财税票档”一体化管理工具，打通员工报销、老板看数与财务处理的业务断点。
- **面向代账机构**：提供多账套批量处理与智能风控引擎，实现规模化提效，将单人服务账套上限提升至 200-300 套。

## 二、 核心业务与技术架构

### 2.1 业财底座与AI双轮驱动

系统坚持“传统业财一体化引擎为承重墙，AI Agent为加速器”的设计理念。底层严格遵循国家最新会计准则，确保账务绝对合规与数据强一致性；上层通过 AI 智能体接管发票识别、科目推荐、自动核销等重活，实现极致提效。

### 2.2 核心人机协同（Human-in-the-loop）机制

在关键业务节点保留人工干预权，消除机构与企业主对 AI 失控的顾虑。AI 负责推荐与草稿生成，人工负责审核与最终确认，确保系统既具备 AI 的提效能力，又保留传统财务软件的严谨性与可控性。

### 2.3 技术架构选型

系统采用“前后端分离 + 微服务 + AI双引擎”架构：

- **前端展示层**：PC端（Vue3 + Element Plus）、员工端（uni-app 微信小程序）、老板端（React Native App/H5）。
- **后端服务层**：Java (Spring Boot) 负责业财核心逻辑与强事务控制；Python (FastAPI) 负责 AI 推理与 Agent 编排。
- **数据持久层**：PostgreSQL（核心账务强一致性）、Redis（缓存与分布式锁）、Milvus（AI向量知识库）、RabbitMQ（异步削峰）。
- **AI中间层**：LangChain Agent 编排 + Drools 规则引擎兜底 + 乐企/OCR 多模态识别。

## 三、 规范驱动开发（SDD）体系

本项目彻底摒弃传统敏捷开发的人海战术，全面采用 **SDD（规范驱动开发） + TDD（测试驱动开发）** 的单人 AI 协同编程范式。人的角色转变为“系统架构师、规范制定者和质量验收官”，AI 作为“执行引擎”严格按照规范生成代码。

### 3.1 核心 Spec 矩阵（26个）

对标用友 BIP 与金蝶星瀚底层架构，项目被精细拆解为 26 个核心 Spec，分为七大层级：

1. **基础设施层**：多租户与数据隔离、统一身份认证与RBAC权限、全局字典与基础档案。
2. **核算底座层**：会计科目体系、会计期间管理、业务单据与状态机、智能核销引擎、凭证生成与过账、总账与多维账簿。
3. **业务扩展层**：费用报销与费控引擎、薪酬核算与个税引擎、农民工工资专户代发。
4. **资金与资产层**：银企直连与支付指令、资金计划与票据管理、固定资产全生命周期管理。
5. **税务合规层**：销项发票与全电票开具、进项发票采集与查验、发票红冲与作废引擎、多税种核算与纳税申报。
6. **期末与报表层**：期末自动化结转、结账控制与反结账、法定财务报表、合并报表与内部交易抵消。
7. **高阶管理与AI层**：全面预算编制与控制、财务共享任务调度、电子会计档案、AI票据识别与智能建单、AI科目推荐与规则兜底、经营分析Agent与NL2SQL。

### 3.2 Loop Engineering 闭环执行流

每个 Spec 的开发均遵循严格的 Loop 闭环：

1. **人**：编写结构化 Spec（Given-When-Then 行为契约）。
2. **人**：基于 Spec 编写 TDD 测试用例（锁定，不可被 AI 篡改）。
3. **AI**：阅读 Spec + 测试，生成实现代码。
4. **自动验证**：运行测试套件（Red → Green）。
5. **人**：Review 关键逻辑（并发、事务、精度），归档沉淀。

## 四、 预期商业价值

- **效能跃升**：帮助接入机构将单人服务账套上限提升至 200-300 套，综合人效提升 150% 以上。
- **体验重塑**：中小微企业报销与审批流转时间缩短 50%，老板通过移动端随时掌握经营数据的渗透率达到 70%。
- **营收升级**：协助合作机构将高附加值业务（合规账、经营分析、税务筹划）的营收占比从不足 10% 提升至 30% 以上。
