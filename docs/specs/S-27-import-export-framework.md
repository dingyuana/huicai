# SPEC：核心数据导入导出能力

## 1. 概述

为 6 个 P0 功能补齐导入导出能力，覆盖科目、客商、凭证、报表、账龄分析、余额调节表。

## 2. 四段模板

### 2.1 输入契约

| 功能 | 输入 | 格式 | 约束 |
|------|------|------|------|
| F-01 科目批量导入 | Excel 文件 | `.xlsx`，第一行为表头 | 表头必须匹配模板，科目编码不可重复 |
| F-01 科目模板下载 | 无 | `.xlsx`，含预填表头 | 表头列：科目编码、科目名称、科目类型、方向、上级编码、辅助核算 |
| F-02 客户导入 | Excel 文件 | `.xlsx` | 表头：客户编码、客户名称、联系人、电话、地址 |
| F-02 供应商导入 | Excel 文件 | `.xlsx` | 表头：供应商编码、供应商名称、联系人、电话、地址 |
| F-03 凭证导出 | 查询条件（期间、凭证类型） | `.xlsx` | 导出当前查询结果 |
| F-04 账龄分析导出 | 账龄区间条件 | `.xlsx` | 导出当前分析结果 |
| F-05 余额调节表 | 银行账户 + 期间 | 页面展示 + `.xlsx` | 自动计算未达账项 |
| F-06 报表导出 | 期间 | `.xlsx` | 导出当前报表数据 |

### 2.2 输出契约

| 功能 | 输出 | 格式 | 说明 |
|------|------|------|------|
| F-01 导入结果 | 成功/失败统计 | 前端弹窗 | 显示导入总数、成功数、失败数 + 失败原因 |
| F-01 模板 | Excel 文件下载 | `.xlsx` | 浏览器下载 |
| F-02 导入结果 | 成功/失败统计 | 前端弹窗 | 同上 |
| F-03 导出 | Excel 文件下载 | `.xlsx` | 含凭证头 + 分录明细 |
| F-04 导出 | Excel 文件下载 | `.xlsx` | 按客户/账龄区间汇总 |
| F-05 页面 | 余额调节表 | HTML 表格 + `.xlsx` | 展示银行余额、企业余额、未达账项 |
| F-06 导出 | Excel 文件下载 | `.xlsx` | 标准财务报表格式 |

### 2.3 状态流转

```
导入流程：
  [上传文件] → [后端解析] → [逐行校验] → [批量写入] → [返回结果]
  失败时：事务回滚，返回错误行号+原因

导出流程：
  [点击导出] → [后端查询数据] → [生成Excel] → [返回文件流] → [浏览器下载]
```

### 2.4 异常处理

| 异常场景 | 处理方式 | 提示信息 |
|----------|---------|---------|
| 文件格式不正确 | 拒绝并提示 | "请上传 .xlsx 格式文件" |
| 模板表头不匹配 | 拒绝并提示 | "模板格式不正确，请下载最新模板" |
| 科目编码重复 | 跳过该行并记录 | "第 X 行：科目编码 XXX 已存在" |
| 导入数据量过大 | 分页处理（每次 500 行） | — |
| 导出无数据 | 提示无数据 | "当前查询无数据，无法导出" |
| 文件过大 | 限制 10MB | "文件大小不能超过 10MB" |

## 3. BDD 验收标准

### F-01 科目批量导入

```
场景：会计导入标准科目
  Given 我下载了科目导入模板
  When 我填写科目数据并上传
  Then 系统提示导入成功，显示导入数量

场景：导入重复科目
  Given 科目编码 1001 已存在
  When 我上传包含 1001 的导入文件
  Then 系统提示第 X 行失败：科目编码 1001 已存在

场景：导入模板格式错误
  When 我上传一个非标准模板的文件
  Then 系统提示"模板格式不正确"
```

### F-02 客商批量导入

```
场景：批量导入客户
  Given 我下载了客户导入模板
  When 我填写客户数据并上传
  Then 系统提示导入成功，显示导入数量

场景：批量导入供应商
  Given 我下载了供应商导入模板
  When 我填写供应商数据并上传
  Then 系统提示导入成功
```

### F-03 凭证导出

```
场景：导出凭证
  Given 我查询了某期间的凭证列表
  When 我点击"导出 Excel"
  Then 浏览器下载了一个 .xlsx 文件
  And 文件包含该期间的所有凭证数据
```

### F-04 账龄分析导出

```
场景：导出账龄分析表
  Given 我查询了应收账龄分析
  When 我点击"导出 Excel"
  Then 浏览器下载了账龄分析表
```

### F-05 余额调节表

```
场景：查看余额调节表
  Given 我已完成银行对账
  When 我点击"余额调节表" Tab
  Then 页面展示银行余额、企业余额、未达账项
  And 借贷平衡

场景：导出余额调节表
  Given 余额调节表已生成
  When 我点击"导出"
  Then 浏览器下载了余额调节表
```

### F-06 报表导出

```
场景：导出资产负债表
  Given 我选择了一个会计期间
  When 我点击"导出 Excel"
  Then 浏览器下载了资产负债表
```

## 4. 权限控制

| 功能 | 权限码 | 控制方式 |
|------|--------|---------|
| 科目导入 | `subjects:import` | 菜单级：会计角色可见 |
| 客户导入 | `party:customer:import` | 菜单级：业务员角色可见 |
| 凭证导出 | `voucher:export` | 菜单级：会计角色可见 |
| 报表导出 | `report:export` | 菜单级：会计角色可见 |

## 5. 技术方案

### 后端通用导入框架

```
POST /api/v1/{resource}/import
  Content-Type: multipart/form-data
  Body: file (Excel .xlsx)

GET /api/v1/{resource}/export-template
  Response: .xlsx file download

GET /api/v1/{resource}/export
  Params: query filters
  Response: .xlsx file download
```

### 前端通用导入组件

- 复用 `el-upload` 组件
- 统一导入结果弹窗（成功/失败统计）
- 统一模板下载按钮

### 通用 Excel 工具

- 后端：Apache POI（已有依赖）
- 前端：不需要额外依赖，后端直接返回文件流
