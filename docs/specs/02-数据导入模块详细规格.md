## 二、功能规格

### F1: 列名映射优化 (P0)

**目标**：对方名称字段在银行对账单中正确提取。

**方案**：从 `ColumnMappingResolver` 的「contains 匹配」改为「精确匹配优先 → 更长的子串匹配优先」:

```
当前: 精确匹配 → contains 匹配(先到先得)
目标: 精确匹配 → 最长子串匹配优先 → 降级为 contains 匹配
```

**规则**：
1. 第一轮：精确匹配 header == alias（不变）
2. 第二轮：按别名长度降序，进行 contains 匹配  
   - "付款人名称" 比 "付款人" 长，所以 column 5 "付款人名称[Payer's Name]" 先匹配到 PAYER_NAME
   - "收款人名称" 比 "收款人" 长，所以 column 9 "收款人名称[Payee's Name]" 先匹配到 PAYEE_NAME
3. 若仍有字段未匹配，对未使用的 column 做最终 contains 降级

**涉及文件**：`ColumnMappingResolver.java`

### F2: 流水去重导入 (P0)

**目标**：同一份 Excel 文件重复导入时自动跳过已存在的记录。

**方案**：以 `交易日期 + 交易流水号 + 金额` 组合键作为唯一标识。

**去重规则**：
1. 导入时，对每条记录计算去重键 `dedupKey = txDate + "|" + externalNo + "|" + amount`
2. 查询数据库中是否有相同 `account_id + txdate + external_no + amount` 的记录
3. 若已存在则跳过（标记为 duplicate），不插入
4. 在前端预览界面显示重复行（灰色标签）

**后端新增**：
- `BankStatementMapper`: `Integer countDuplicate(Long accountId, LocalDate txDate, String externalNo, BigDecimal amount)`
- `BankStatementExcelImportService.previewExcel()`: 解析时检查重复
- `BankStatementExcelImportService.confirmImport()`: 插入前再检查一次（防止并发）

**涉及文件**：`BankStatementMapper.java`, `BankStatementExcelImportService.java`

### F3: 单条流水删除 (P0)

**目标**：前端对账单列表中增加删除按钮，支持软删除单条流水。

**后端**：
- `BankStatementController`: `DELETE /api/v1/bank-statements/{id}`
- `BankStatementService`: `void delete(Long id)` — 逻辑删除（deleted=1）

**前端**：
- `BankStatementView.vue`: 表格操作列增加"删除"按钮
- 删除前弹确认对话框

**涉及文件**：`BankStatementController.java`, `BankStatementService.java` + impl, `BankStatementView.vue`

### F4: 一键清空测试数据 (P1)

**目标**：系统设置中增加数据清理功能，一键清空银行流水、发票导入记录、自动生成的凭证。

**功能点**：

| 子功能 | 说明 |
|:---|:---|
| 清空范围选择 | 支持选择清空范围：仅银行流水 / 仅发票记录 / 全部（流水+发票+生成的凭证） |
| 权限控制 | 仅管理员可操作（`system:clear:data`） |
| 二次确认 | 弹窗提示影响范围，输入"确认清空"文字后执行 |
| 操作审计 | 清空操作记录到审计日志，记录清空范围和执行时间 |

**后端**：
- `ClearDataService.java`: `clearBankStatements()`, `clearInvoiceRecords()`, `clearAll()`
- `ClearDataController.java`: `POST /api/v1/system/clear-data`
- 实际为物理删除（DELETE FROM 表 WHERE 条件）
- 删除的关联数据：银行流水 → 生成的凭证（DRAFT）→ 生成的业务单据（DRAFT源码=FROM_BANK_TXN/INVOICE_IMPORT）

**前端**：
- 系统设置 → 数据维护 → 清空数据

**涉及文件**：`ClearDataService.java`, `ClearDataController.java`, `ClearDataView.vue`, `base.ts`(路由), `AppSidebar.vue`
