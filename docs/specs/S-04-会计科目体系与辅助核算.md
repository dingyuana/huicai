## 概述

多级树形科目结构、辅助核算多维绑定、行业模板加载。当前代码已有完整的科目管理实现。

**已有代码基础**：
- `Subject` Entity：映射 `t_subject` 表，含 code/name/parentId/level/direction/isLeaf/auxCalcType
- `SubjectController`：科目树查询、CRUD、国标导入（6 个端点）
- `SubjectServiceImpl`：
  - `getTree()`：递归构建科目树
  - `create()`/`update()`：含科目编码唯一性校验、辅助核算类型校验、层级自动计算
  - `delete()`：含科目已使用检查（逻辑删除 deleted=0）
  - `importStandard()`：一键导入国家标准 6 类一级科目（资产/负债/权益/成本/损益/共同）
  - `validateAuxCalcType()`：校验辅助核算类型
  - 导入时自动为应收/预收设 customer、应付/预付设 vendor、其他应收设 employee
- `SubjectTreeVO`：树形展示 VO
- `SubjectCreateDTO`/`SubjectUpdateDTO`：入参 DTO

**DB 表结构（t_subject）**：
```sql
CREATE TABLE t_subject (
    id              BIGINT PRIMARY KEY,
    code            VARCHAR(50)  NOT NULL,
    name            VARCHAR(200) NOT NULL,
    parent_id       BIGINT,
    level           INTEGER      NOT NULL DEFAULT 1,
    direction       VARCHAR(10)  NOT NULL DEFAULT 'debit',
    is_leaf         BOOLEAN      NOT NULL DEFAULT TRUE,
    aux_calc_type   VARCHAR(50),
    is_active       BOOLEAN      NOT NULL DEFAULT TRUE,
    remark          VARCHAR(500),
    created_by      BIGINT,
    created_at      TIMESTAMP,
    updated_by      BIGINT,
    updated_at      TIMESTAMP,
    deleted         INTEGER      NOT NULL DEFAULT 0,
    -- 约束
    CONSTRAINT uq_subject_code UNIQUE (code),
    CONSTRAINT chk_direction CHECK (direction IN ('debit', 'credit')),
    CONSTRAINT chk_aux_calc_type CHECK (aux_calc_type IS NULL OR aux_calc_type IN
        ('customer', 'vendor', 'department', 'project', 'employee'))
);
```

## 1. 输入契约

### 1.1 创建科目

| 参数 | 类型 | 约束 | 说明 |
|------|------|------|------|
| code | String | 非空，全局唯一 | 科目编码 |
| name | String | 非空 | 科目名称 |
| parentId | Long | 可空 | 父科目 ID（空=一级科目） |
| direction | String | 枚举：debit/credit | 借贷方向 |
| auxCalcType | String | 枚举：customer/vendor/department/project/employee | 辅助核算类型 |
| isActive | Boolean | 默认 true | 是否启用 |
| remark | String | 可空，≤500字 | 备注 |

### 1.2 前置条件

- 如有 parentId，父科目必须存在且 deleted=0
- code 不能与已有科目重复（含已删除的）
- direction 必须与父科目一致（如有父科目）

## 3. 状态流转

### 3.1 科目启用状态

```
ACTIVE -> INACTIVE -> ACTIVE
```

| 状态 | 说明 | 可转换到 |
|------|------|---------|
| ACTIVE (is_active=true) | 正常使用 | INACTIVE |
| INACTIVE (is_active=false) | 停用 | ACTIVE |

### 3.2 科目删除（逻辑删除）

```
deleted=0 (正常) -> deleted=1 (已删除)
```

- 只能删除未被使用的科目（无凭证分录引用）
- 删除后 code 仍占用（防止重建冲突）

### 3.3 末级科目变更

- 创建子科目时，父科目的 is_leaf 从 true -> false
- 删除唯一子科目时，父科目的 is_leaf 从 false -> true

### 3.4 负向断言

- 已停用的科目不能用于凭证录入
- 已删除的科目不能出现在科目树中
- 非末级科目不能直接记账（凭证分录只能选择末级科目）
- 父科目的 direction 不能与子科目不同

### 3.5 辅助核算绑定规则（国标导入时自动设置）

| 科目 | auxCalcType | 说明 |
|------|-------------|------|
| 应收账款 (1122) | customer | 客户辅助 |
| 预收账款 (2203) | customer | 客户辅助 |
| 应付账款 (2202) | vendor | 供应商辅助 |
| 预付账款 (1123) | vendor | 供应商辅助 |
| 其他应收款 (1221) | employee | 员工辅助 |
| 其他科目 | null | 无辅助核算 |

## 验收标准（BDD）

### 场景 1：创建一级科目
- **Given** 系统中无编码为 "1001" 的科目
- **When** POST /api/v1/subjects {code: "1001", name: "库存现金", direction: "debit"}
- **Then** 返回 200，科目创建成功
- **And** level = 1, isLeaf = true, parentId = null, deleted = 0

### 场景 2：创建子科目（父科目 isLeaf 变更）
- **Given** 科目 "1001" 存在，isLeaf = true
- **When** POST /api/v1/subjects {code: "100101", name: "人民币", parentId: 1, direction: "debit"}
- **Then** 返回 200，子科目创建成功
- **And** level = 2, isLeaf = true
- **And** 父科目 "1001" 的 isLeaf 变为 false

### 场景 3：科目编码重复
- **Given** 科目编码 "1001" 已存在
- **When** POST /api/v1/subjects {code: "1001", name: "现金"}
- **Then** 返回错误码 20104「科目编码已存在」
- **And** 不创建新科目

### 场景 4：非末级科目禁止记账
- **Given** 科目 "1001" 的 isLeaf = false（有子科目）
- **When** 凭证录入时选择 "1001" 作为科目
- **Then** 返回错误码 20102「非末级科目禁止记账」
- **And** 凭证不创建

### 场景 5：科目已被使用禁止删除
- **Given** 科目 "100101" 已在凭证分录中使用
- **When** DELETE /api/v1/subjects/{id}
- **Then** 返回错误码 20105「科目已被使用，不能删除」
- **And** deleted 保持 0

### 场景 6：辅助核算类型校验
- **Given** 创建科目时传入 auxCalcType = "invalid_type"
- **When** POST /api/v1/subjects {code: "9999", name: "测试", auxCalcType: "invalid_type"}
- **Then** 返回错误码 20117「辅助核算类型不合法」
- **And** 不创建科目

### 场景 7：一键导入国家标准科目
- **Given** 系统为空（无科目）
- **When** POST /api/v1/subjects/import-standard
- **Then** 返回导入数量（如 6 个一级科目）
- **And** 应收账款科目 auxCalcType = "customer"
- **And** 应付账款科目 auxCalcType = "vendor"
- **And** 其他应收款科目 auxCalcType = "employee"
- **And** 重复导入不会产生重复数据

### 场景 8：获取科目树
- **Given** 系统有多个层级的科目
- **When** GET /api/v1/subjects/tree
- **Then** 返回 200 + 树形结构
- **And** 树中不包含 deleted=1 的科目
- **And** 树中不包含 is_active=false 的科目（除非查询时显式要求）

### 场景 9：direction 与父科目不一致
- **Given** 父科目 "1001" direction = "debit"
- **When** POST /api/v1/subjects {code: "100102", parentId: 1, direction: "credit"}
- **Then** 返回错误码 20119「借贷方向与父科目不一致」
- **And** 不创建子科目
