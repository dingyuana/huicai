## 验收标准（BDD）

### 场景 1：母子公司合并报表正常生成
- **Given** 集团架构包含母公司 A 和子公司 B，合并范围已配置为 A+B，双方已结账并生成单体报表，抵消规则已配置
- **When** 财务人员发起合并报表生成操作，系统执行内部交易识别和抵消分录生成
- **Then** 系统生成合并资产负债表、合并利润表、合并现金流量表，抵消分录状态为 DRAFT，合并范围状态流转至 EXECUTING

### 场景 2：内部交易自动识别与抵消
- **Given** 母公司 A 于本月向子公司 B 销售商品 100 万元（含税），双方均已确认入账
- **When** 系统执行内部交易识别和抵消
- **Then** 系统自动识别该笔内部销售，生成抵消分录：借"营业收入"100 万元，贷"营业成本"100 万元，抵消分录状态为 DRAFT

### 场景 3：合并范围未审核阻断执行
- **Given** 合并范围配置为 A+B+C，但该合并范围尚未经过审核，状态为 DRAFT
- **When** 财务人员尝试执行合并报表生成
- **Then** 系统检测到合并范围未审核，返回错误码 20114，拒绝执行合并，提示用户先完成合并范围审核

### 场景 4：内部交易未识别时提示人工核查
- **Given** 母公司 A 与子公司 B 之间存在一笔 50 万元的往来款，但双方入账科目不一致（A 挂"其他应收款"，B 挂"应付账款"）
- **When** 系统执行内部交易匹配识别
- **Then** 系统无法自动匹配该笔交易，返回错误码 20115，标记为"未识别交易"，提示用户人工核查并补充抵消规则

### 场景 5：抵消规则冲突处理
- **Given** 同一笔内部交易同时匹配了"全额抵消"和"比例抵消（70%）"两条冲突规则
- **When** 系统执行抵消分录生成
- **Then** 系统检测到规则冲突，返回错误码 20116，暂停合并流程，提示用户修正抵消规则配置
