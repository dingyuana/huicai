## 验收标准（BDD）

### 场景 1：新增资产卡片并正常折旧
- **Given** 企业购入一台价值 120 万元的生产设备，预计使用年限 10 年，残值率 5%，折旧方法为"年限平均法"
- **When** 资产管理员录入资产卡片信息，提交后系统自动开始按月计提折旧
- **Then** 资产卡片状态为 IN_USE，系统每月计算折旧额 9500 元（(1200000-60000)/120），生成折旧凭证（DRAFT），折旧状态为"折旧中"

### 场景 2：资产调拨变动
- **Given** 资产编号 FA-2023-001 的电脑当前由研发部使用，状态为 IN_USE
- **When** 管理员发起资产调拨，将资产从研发部调拨至行政部
- **Then** 系统生成资产变动凭证（DRAFT），资产台账中使用部门更新为行政部，调拨记录留痕

### 场景 3：已处置资产禁止折旧
- **Given** 资产编号 FA-2022-005 的打印机已做清理处置，状态为 DISPOSED
- **When** 系统执行本月折旧计算时包含该资产
- **Then** 系统检测到资产已处置，跳过该资产的折旧计算，返回错误码 20307，在折旧报告中提示"资产已处置，跳过折旧"

### 场景 4：不支持的折旧方法
- **Given** 资产卡片选择的折旧方法为"双倍余额递减法"，但系统当前仅支持"年限平均法"和"工作量法"
- **When** 用户提交资产卡片保存请求
- **Then** 系统返回错误码 20308，提示折旧方法不支持，资产卡片不予保存

### 场景 5：资产到期清理全流程
- **Given** 资产编号 FA-2015-003 的设备已到达使用年限，累计折旧已提足，残值已处理完毕
- **When** 管理员发起资产清理操作，填写清理原因"到期报废"
- **Then** 资产状态由 IN_USE 流转至 DISPOSED 再至 SCRAPPED，生成清理凭证（DRAFT），资产台账标记为已清理
