## 概述

期间开启/关闭/锁定逻辑、跨年结转、写入拦截机制。当前代码已有完整的会计期间管理和期末结账实现。

**已有代码基础**：
- `PeriodEntity`：映射 `t_period` 表，含 year/month/periodCode/startDate/endDate/status
- `PeriodController`：期间 CRUD（6 个端点，/api/v1/periods）
- `PeriodService`/`PeriodServiceImpl`：期间分页/全量查询、增删改
- `PeriodCloseController`：期末结账（5 个端点，/api/v1/period-close）
- `PeriodCloseServiceImpl`：结账前检查 + 损益结转 + 执行结账 + 反结账 + 结账日志
- `@StatusChangeable` 注解：期间状态变更触发审计日志

**已实现结账前检查项**：
1. 期间状态必须为 OPEN（CLOSED/LOCKED 不能结账）
2. 不能有未过账凭证（status != POSTED）
3. 试算必须平衡（借方发生 = 贷方发生）
4. 不能有草稿状态的红冲凭证未提交

**DB 表结构（t_period）**：
```sql
CREATE TABLE t_period (
    id          BIGINT PRIMARY KEY,
    year        INTEGER     NOT NULL,
    month       INTEGER     NOT NULL CHECK (month >= 1 AND month <= 12),
    period_code VARCHAR(20) NOT NULL,
    start_date  DATE        NOT NULL,
    end_date    DATE        NOT NULL,
    status      VARCHAR(20) NOT NULL DEFAULT 'open',
    created_by  BIGINT,
    created_at  TIMESTAMP,
    updated_by  BIGINT,
    updated_at  TIMESTAMP,
    deleted     INTEGER     NOT NULL DEFAULT 0,
    CONSTRAINT uq_period_code UNIQUE (period_code),
    CONSTRAINT chk_period_status CHECK (status IN ('open', 'closed', 'locked'))
);
```

**凭证与期间的关系**：`VoucherEntity.period` 字段存储期间编码（YYYYMM 格式字符串）。

- 期间存在且 status = OPEN
- 该期间内无未过账凭证
- 该期间试算平衡
- 该期间无草稿状态的红冲凭证

## 3. 状态流转

### 3.1 期间状态机

```
OPEN -> CLOSED -> LOCKED
         ↓
      (反结账)
         ↓
       OPEN
```

| 状态 | 说明 | 可转换到 | 写入拦截 |
|------|------|---------|---------|
| OPEN | 开启，可录入凭证 | CLOSED | 否 |
| CLOSED | 已结账，不能录入 | LOCKED, OPEN（反结账） | 是 |
| LOCKED | 已锁定，不能修改 | （终态，需管理员解锁） | 是 |

### 3.2 状态转换触发

| 转换 | 触发方法 | 前置条件 |
|------|---------|---------|
| OPEN -> CLOSED | `closePeriod()` | 结账前检查全部通过 |
| CLOSED -> OPEN | `reopenPeriod()` | 反结账（需人工触发） |
| CLOSED -> LOCKED | 管理员锁定 | 人工操作 |

### 3.3 负向断言

- CLOSED 状态的期间不能创建新凭证
- LOCKED 状态的期间不能反结账
- CLOSED 状态的期间不能修改已有凭证
- 不能跳过结账前检查直接结账

### 3.4 结账前检查清单

| 检查项 | 通过条件 | 不通过提示 |
|--------|---------|------------|
| 期间状态 | status = OPEN | "期间已结账" / "期间已锁定" |
| 未过账凭证 | count = 0 | "存在 N 张未记账凭证" |
| 试算平衡 | 借方发生 = 贷方发生 | "试算不平衡, 借方发生 X / 贷方发生 Y" |
| 红冲凭证草稿 | count = 0 | "存在 N 张草稿状态的红冲凭证未提交" |

### 3.5 损益结转

- 结账时自动生成损益结转凭证（DRAFT 状态）
- 收入类科目 -> 本年利润（贷方）
- 费用类科目 -> 本年利润（借方）
- 结转后收入/费用科目余额为 0

### 3.6 反结账

- 将期间状态从 CLOSED 恢复为 OPEN
- 记录反结账日志（操作人/时间/原因）
- 已锁定（LOCKED）的期间不能反结账

## 4. 异常处理

| 异常场景 | 错误码 | 降级策略 |
|---------|--------|---------|
| 期间已锁定 | 20103 | 拦截写入操作 |
| 期间不存在 | 20106 | 拦截操作 |
| 结账前检查不通过 | - | 返回 issues 列表，不执行结账 |
| 试算不平衡 | 20108 | 返回差异金额，不执行结账 |
| 反结账条件不满足 | 20113 | 拦截反结账 |

## 验收标准（BDD）

### 场景 1：创建会计期间
- **Given** 系统中无 202607 期间
- **When** POST /api/v1/periods {year: 2026, month: 7, periodCode: "202607", startDate: "2026-07-01", endDate: "2026-07-31"}
- **Then** 返回 200，期间创建成功
- **And** status = "open", deleted = 0

### 场景 2：结账前检查通过
- **Given** 期间 202607 status = OPEN，所有凭证已过账，试算平衡
- **When** GET /api/v1/period-close/check?period=202607
- **Then** 返回 passed = true, issues = []
- **And** trialBalance.balanced = true

### 场景 3：结账前检查不通过（有未过账凭证）
- **Given** 期间 202607 有 3 张未过账凭证
- **When** GET /api/v1/period-close/check?period=202607
- **Then** 返回 passed = false
- **And** issues 包含 "存在 3 张未记账凭证"

### 场景 4：执行结账
- **Given** 期间 202607 结账前检查通过
- **When** POST /api/v1/period-close/close?period=202607
- **Then** 期间 status 变为 "closed"
- **And** 记录结账日志
- **And** 该期间不能创建新凭证

### 场景 5：已结账期间写入被拦截
- **Given** 期间 202607 status = CLOSED
- **When** 尝试在该期间创建新凭证
- **Then** 返回错误码 20103「期间已锁定」
- **And** 凭证不创建

### 场景 6：反结账
- **Given** 期间 202607 status = CLOSED
- **When** POST /api/v1/period-close/reopen?period=202607
- **Then** 期间 status 恢复为 "open"
- **And** 记录反结账日志
- **And** 该期间可以重新录入凭证

### 场景 7：已锁定期间不能反结账
- **Given** 期间 202607 status = LOCKED
- **When** POST /api/v1/period-close/reopen?period=202607
- **Then** 返回错误「期间已锁定, 不能结账」
- **And** 期间状态不变

### 场景 8：损益结转凭证生成
- **Given** 期间 202607 有收入和费用科目余额
- **When** POST /api/v1/period-close/profit-carryover?period=202607
- **Then** 返回损益结转凭证 ID
- **And** 凭证状态为 DRAFT
- **And** 收入类科目余额归零
- **And** 费用类科目余额归零

### 场景 9：试算不平衡不能结账
- **Given** 期间 202607 借方发生 100000，贷方发生 95000
- **When** GET /api/v1/period-close/check?period=202607
- **Then** 返回 passed = false
- **And** issues 包含 "试算不平衡"
- **And** POST /api/v1/period-close/close 被拦截
