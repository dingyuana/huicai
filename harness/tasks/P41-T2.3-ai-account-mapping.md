在 AI 服务中增加 pgvector 商品名→科目相似度检索接口

## 关联 SPEC
docs/specs/P41-invoice-driven-finance.md §2.3

## 具体要求
### 1. 修改文件
| 文件 | 修改内容 |
|------|----------|
| ai-service/app/api/account_mapping.py | 新增 pgvector 科目映射推荐接口 |
| ai-service/app/core/config.py | 补充 pgvector 连接配置 |

### 2. AI 接口
```python
POST /ai/v1/account/mapping
Request: {"item_name": "A产品", "direction": "OUTPUT"}
Response: {
  "recommendations": [{"account_code": "6001", "account_name": "主营业务收入", "confidence": 0.95}],
  "top_match": {"account_code": "6001", "account_name": "主营业务收入", "confidence": 0.95}
}
```

### 3. 验收标准
- 商品名→科目向量相似度检索准确率 ≥ 90%
- 未匹配商品自动挂起，提示人工补全
- AI 结果写入 t_tax_invoice.ai_mapping_result（JSONB）

## 不要做
- 不要修改 Java 后端
- 不要自动应用 AI 推荐结果到财务数据
