# P41-T2.4 任务：凭证生成前置校验 + 批量合并制单（手动触发）

> 状态：待审核 | 优先级：中 | 预计工时：0.5 人日

## 任务描述
业务单据审核通过后，财务人员**手动点击**"生成凭证"按钮触发凭证生成（DRAFT）。
生成前做借贷平衡、辅助核算完整性校验。

## 关联 SPEC
docs/specs/P41-invoice-driven-finance.md §1.3

## 具体要求

### 1. 关键设计

#### 新增"生成凭证"端点（手动触发）
- POST /api/v1/tax/invoice/{id}/generate-voucher
  - 从发票/业务单据中提取商品明细
  - 根据科目映射规则（t_account_mapping_rule）自动填充借贷分录
  - 创建 Voucher status = DRAFT
- POST /api/v1/tax/invoice/batch/generate-voucher
  - 多张发票合并生成一张凭证

#### 凭证状态流转（参考现有 VoucherStatus）
```
DRAFT → 人工提交审核 → SUBMITTED → 人工审核 → AUDITED → 人工过账 → POSTED
  ↕
  VOIDED
```

### 2. 修改文件
| 文件 | 修改内容 |
|------|----------|
| VoucherController.java | 新增批量生成凭证端点 |
| VoucherServiceImpl.java | 生成凭证前校验借贷平衡、辅助核算完整性 |
| TaxController.java | 新增 generateVoucher 端点 |

### 3. 验收标准
- 借贷不平衡阻止生成，返回明确错误信息
- 必填辅助核算缺失时提示
- 多张发票可合并生成一张凭证
- 凭证保持 DRAFT 不变，不自动审核/过账

## 不要做
- 不要自动审核凭证（保持 DRAFT）
- 不要自动过账
